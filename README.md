- **CacheRL trains small tool-calling agents near frontier accuracy with cached rollouts at ~100x less compute** — A June 12 arXiv paper, CacheRL: Multi-Turn Tool-Calling Agents via Cached Rollouts and Hybrid Reward (arXiv:2606.14179), targets the most expensive part of fine-tuning small agent models: reinforcement learning over multi-turn tool use normally requires live tool execution thousands of times per batch. CacheRL replays a three-tier fuzzy cache of past trajectories with token-level masking to avoid live calls, and pairs it with a cache-tier-aware hybrid reward that reweights answer quality so the model is not penalized for limitations the cache introduces. The authors report 92% process accuracy on multi-step tool-calling, approaching GPT-5's reported 94%, while using roughly 100x less compute, and lift validation reward on Qwen3-4B-Thinking from 0.43 to 0.78; ablations credit a 41% drop to removing knowledge transfer and a 17% gain to the cache-aware reward. The result is a concrete recipe for distilling tool-calling competence into a small open model without a costly live-execution RL loop.
