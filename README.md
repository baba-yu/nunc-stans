- **A critical prompt-injection-to-RCE flaw in the Langroid LLM-agent framework (CVE-2026-25879, CVSS 9.8) keeps the agentic SQL attack surface in the spotlight** -- A newly published advisory pins a CVSS 9.8 critical rating on CVE-2026-25879 in Langroid, a popular open-source framework for building LLM-powered applications. The flaw lives in Langroid's SQLChatAgent, which executes SQL produced by the model - and because that SQL is steerable by prompt injection, an attacker who can shape the agent's input (directly via a malicious prompt, or indirectly by poisoning data the model later reads) can coerce dangerous, dialect-specific primitives.
