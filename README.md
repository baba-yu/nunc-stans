- **MosaicQuant splits weights into a dense plus sparse 4-bit pair to keep near-FP16 accuracy** — A paper posted to arXiv on June 14 (arXiv:2606.15652, cs.LG and cs.CL) proposes MosaicQuant, a 4-bit large-language-model quantization scheme aimed at the tension between compressing the dense bulk of a weight matrix and faithfully preserving the rare large-magnitude outliers that 4-bit grids tend to clip. Rather than fall back on a mixed-precision format, MosaicQuant disaggregates each weight matrix into a dense 4-bit base component that captures most values and a sparse 4-bit residual component that compensates for quantization error in the most error-sensitive blocks, so both pieces stay in 4-bit. To keep that two-part representation from re-introducing the overhead mixed-precision methods usually pay, the authors add ZipperEngine, which folds the sparse residual computation into the dense 4-bit matrix operations through an overlapped pipeline, preserving a unified low-bit execution path. On LLaMA3 and Qwen3 models the method is reported to retain near-FP16 accuracy while delivering up to a 1.24x speedup over the 16-bit baseline. As with any single-paper result the numbers are the authors' own and await independent reproduction and broader model coverage, but the work is a concrete data point in the effort to make 4-bit serving the default for memory-constrained local deployment rather than a lossy fallback. [arXiv:2606.15652 - MosaicQuant: Inlier-Outlier Disaggregation for Unified 4-Bit LLM Quantization](https://arxiv.org/abs/2606.15652)
