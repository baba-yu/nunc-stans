- **Vertex AI SDK のテナント越えRCE、ステージング用バケットの先取りが原因** — Palo Alto Networks の Unit 42 は6月16日、Google Cloud の Vertex AI SDK for Python(v1.139.0 および v1.140.0)に存在する、テナントをまたぐリモートコード実行の連鎖を「Pickle in the Middle」として公開した。開発者がステージング用バケットを指定しなかった場合、SDK は決まった既定名(project-id-vertex-staging-region)を自動生成し、そのバケットが存在することだけを確認して、呼び出し元が所有者かどうかは確認しなかった。被害者のプロジェクトIDを知る攻撃者は、そのバケットを事前に作成(バケットの先取り)し、被害者のモデルアップロードを捕捉して、汚染されたアーティファクトにすり替えられた。Vertex のモデルは通常 pickle か joblib でシリアライズされるため、細工された __reduce__ メソッドは、Google のサービングコンテナがオブジェクトをデシリアライズした瞬間に任意のコードを実行し、続いてメタデータサーバーから cloud-platform 権限を持つサービスアカウントの OAuth トークンを抜き取る。Unit 42 は3月5日に Google の VRP 経由で報告した。Google は v1.144.0(3月31日)でバケット名にランダムな UUID を加え、v1.148.0(4月15日)で完全な所有権検証を加えた。CVE は割り当てられていない。 [Palo Alto Networks Unit 42 - Pickle in the Middle: Hijacking Vertex AI Model Uploads for Cross-Tenant RCE](https://unit42.paloaltonetworks.com/hijacking-vertex-ai-model/), [The Hacker News - Google Vertex AI SDK Flaw Let Attackers Hijack Model Uploads via Bucket Squatting (June 16, 2026)](https://thehackernews.com/2026/06/google-vertex-ai-sdk-flaw-let-attackers.html), [CSO Online - Google's Vertex AI SDK could allow RCE through bucket squatting](https://www.csoonline.com/article/4186193/googles-vertex-ai-sdk-could-allow-rce-through-bucket-squatting.html)

### Predictions check

本日の動きは四つの流れにきれいに分かれる。AI セキュリティの突破、非 GPU シリコンの節目、リリース前の安全性手法、そして大手データプラットフォームのサミット最終日だ。そして共通の筋は、いずれもモデルそのものではなくモデルの一段下の基盤を固めている、という点にある。最も整合性の高い裏付けはセキュリティの流れだ。Palo Alto の Unit 42 が6月16日に公表した「Pickle in the Middle」は、Google の Vertex AI SDK における予測可能な既定のステージング用バケット名を、テナント間のリモートコード実行へと変える。被害者のプロジェクト ID を知る攻撃者があらかじめバケットを作っておき、モデルのアップロードを捕まえ、__reduce__ メソッドが Google の配信コンテナのデシリアライズと同時に任意コードを実行する汚染された pickle をすり替え、続いてクラウドプラットフォームにスコープされた OAuth トークンを抜き取る。これは、署名付きチェックポイントローダーの諸仮説がこれまで得た中で最も強力な単一インシデントの裏付けだ。Agent-framework loaders ship signed-checkpoint and manifest mode の予測（5月11日）と Open-source serving stacks ship signed-checkpoint loading as default の予測（5月12日）は、いずれもまさにこのロード時の任意コード実行という弱点を狙っており、Google の修正の道筋、すなわちランダムな UUID のバケット名に続く完全な呼び出し元の所有権検証は、両者が既定になると見込む証明付き来歴の姿勢である。公表されたテナント間突破は、成果物の信頼をオプトインから既定へと移す引用可能な根拠を、より広いフレームワーク群に与える。とはいえ、これに応じてその既定を切り替えたエージェントフレームワークやオープン配信スタックはまだない。

データプラットフォームの流れは広がりで支配的だ。Data + AI Summit の最終日に Databricks は、Lakebase を初の真の LTAP、すなわち即時の copy-on-write ブランチ機能とガバナンス付きエージェントメモリを備えたマネージドのサーバーレス Postgres データベースとして位置づけ直し、Genie を Genie One、すなわち有料を前提としたコワーカースイート（Genie Agents・App Builder・Lakeflow Designer・ZeroOps、Teams と M365 Copilot のベータを伴う）へと拡張した。この一手は、Durable agent-execution substrate hardens into a standard primitive の予測（6月12日）へのほぼ直撃に近い。その主張が明確に、本番エージェントには単なるモデルエンドポイントではなく安全なブランチ機能を備えた低遅延のトランザクションストアが必要だ、というものだからだ。さらにこれは、オープンコアの収益化という読みにおいて Omnigent ships as a paid Databricks-managed agent-orchestration tier の予測（6月15日）を厚くする。加えて本日の休眠予測の復活の大半を牽引する。四つの行が復活した。Governed agent-ontology layer hardens into the enterprise-agent moat の予測（6月3日）は、Databricks が再びエージェントが消費するガバナンス付きコンテキストの領域を築いていることによる。Snowflake ships a metered Claude-in-Cortex governed-data agent tier の予測（6月2日）は、競合のデータプラットフォームがガバナンス付きで消費量に応じた形のエージェント領域を出荷したことによる。Hyperscaler custom AI silicon splits into training vs inference SKUs の予測（4月22日）は、d-Matrix の推論専用部品による。そして AMD Helios plus MI450 commitment book clears 15GW の予測（5月20日）は、AMD の7月23日の Advancing AI という予定への薄い言及による。

シリコンと安全性の流れが、ストリームをまたぐこのパターンを締めくくる。d-Matrix は6月9日に、Corsair 推論アクセラレータが SquadRack ラックスケール設計（Arista・Broadcom・Supermicro とともに構築）とともに本格量産に入ったと発表した。これは SRAM と計算をオンダイで融合し、トランスフォーマーのデコードのメモリ帯域の壁を突く、デジタルなインメモリ計算チップレットであり、Gimlet Labs の独立検証でおよそ12倍の遅延改善を示し、単体 GPU と比べて約10倍速く、3倍安く、最大5倍エネルギー効率が高い推論だという同社の主張を伴う。これは、開示された金額や株価の動きを示さないまま、カスタムアクセラレータの年率換算収益と ASIC 格下げの諸仮説（6月3日、6月7日）に領域の追い風として作用する。OpenAI の6月16日の Deployment Simulation が安全性の流れをもたらす。約130万件の匿名化された ChatGPT の会話を候補モデルで再生して挙動のずれを予測し、報告された乗算誤差の中央値はおよそ1.5倍で、これまで見えていなかった「電卓ハッキング」の不整合を浮かび上がらせ、シミュレートされたツール呼び出しを通じてエージェント的なコーディングへ広げた。それはフロンティアラボの安全性フレームワークの収束と定量的危害しきい値の諸仮説（6月5日、5月29日）を前進させ、Coding-agent frameworks ship goal-grounded completion verification の予測（6月7日）に隣接する。電卓ハッキングこそ、その検証の軸が狙う、主張と実際の操作の間のずれそのものだからだ。先を見た予定表は三つのサブトラックすべてで埋まったままだ。6月18日に閉幕する Data + AI Summit、6月29日から7月2日まで専用の Inference と Security のトラックを擁する AI Engineer World's Fair、6月23〜24日の Confidential Computing Summit、7月23日の AMD の Advancing AI、そして8月23〜25日の Hot Chips が、これらの基盤とガバナンスの流れが次に前進する会場である。
