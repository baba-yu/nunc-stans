推論サービングと量子化の話題こそが、このリリースをリーダーボードの一行から自前運用の選択肢へと変えるもので、本日で最も整合性の高いまとまりを成す。vLLM は6月15日に v0.23.0 をタグ付けし(408コミット、200名の貢献者)、Model Runner V2 の実行経路を Llama と Mistral の dense モデルの既定に昇格させ、DeepSeek-V4 を各バックエンドで成熟させ、Rust フロントエンドとレガシーな Python サーバーとの差を縮めた。並行して、6月14日に投稿された arXiv 論文が MosaicQuant を紹介している。各重み行列を dense な4ビットのベースとスパースな4ビットの残差に分解し、ZipperEngine の重なりで統合するもので、FP16 に近い精度と、LLaMA3 および Qwen3 で16ビットのベースラインに対し最大1.24倍の高速化を報告する。GLM-5.2 のリリースと併せて読むと、これらは本日の将来予測が拠り所とする導入コストの除去要因だ。最上位のオープンウェイトのコーダーと、より安価な4ビット推論が同じ週に到来したのである。この合流が、本日の主要予測(MIT または Apache-2.0 のオープンウェイトのコーダーが2026年Q4までに Terminal-Bench 2.1 で85.0 に到達)と、より明確な自前運用の姿勢に関する予測(名指しの企業またはツールフレームワークが、データ主権を理由に、外部ホスト型 API ではなくオープンウェイトの自前運用を既定として公表することが2027年Q2までに起きる)の根拠となっている。

フィジカル AI の筋は別個に走るが、資本面で韻を踏む。Neura Robotics は最大14億ドルのシリーズ C(6月10日に表面化、約70億ドルとされる評価額)を開示し、半導体とクラウドの戦略投資家を直接キャップテーブルに引き入れている。Nvidia、Amazon、Qualcomm、Bosch、Schaeffler、欧州投資銀行、imec.xpand、Lingotto Horizon に加え Tether 主導のシンジケートも参加し、4NE-1 ヒューマノイドの量産を2030年までに数百万台規模へ拡大する資金に充てられる。これは本日のヒューマノイド資金調達の予測(別のフルスタックのヒューマノイドメーカーが、重複する半導体またはクラウドの出資者とともに5億ドル超の戦略ラウンドを2026年Q4までに成立させる)の裏付けとなる。検証の側では、復活の大半がオープンウェイトのコーダーというテーマでの休眠予測だ。コンシューマー向け GPU のコーディングエージェントがクラウド API を置き換える項(4月26日)と、米国のオープンウェイトが Artificial Analysis Index で54を超える項(6月4日)は、いずれも GLM-5.2 とより安価な推論によって復活する。Kimi K2.7-Code が独立した SWE-bench スコアに到達する項(6月13日)は同じ「ベンダー報告のあと検証待ち」の流れを再現し、コンフィデンシャル GPU のアテステーションを契約条件とする項(6月14日)は、Confidential Computing Summit(6月23〜24日)が近づいたことだけで一歩進む。GLM-5.2 の自前運用の話題がその議題に織り込むのと同じデータ主権の筋が、ここにも通っている。いつものとおり、名指しされた各到達点は本日の証拠が指し示すにとどまり、まだ実現されてはいない。
