- **NVIDIAの学習不要SpatialClawが20種の空間推論ベンチマークで首位** — NVIDIAの研究者らは6月19日、SpatialClawを公開した。視覚言語モデルが、モデル固有・ベンチマーク固有の調整なしに、物体の位置特定や3次元の関係について推論できるようにする、学習不要のフレームワークである。再学習する代わりに、入力フレームと知覚プリミティブをあらかじめ読み込んだステートフルなPythonカーネルをラップし、エージェントはステップごとにそのカーネルへPythonのセルを1つずつ書き込む。これにより、作業の途中で重心距離のヒューリスティックからKD木による最近傍探索へ切り替えるといった、真のテスト時計算が可能になる。報告された結果は、code-as-action(行動としてのコード)が従来のツール利用手法を上回ることを示している。20種の空間ベンチマークで平均精度59.9%、SpaceToolsのベースラインを+11.2ポイント上回り、最も大きな伸びは動的なタスクで見られ、26Bから397Bパラメータの6つのバックボーン間で一貫していた。コードはGitHub(NVlabs/SpatialClaw)で公開され、プロジェクトページと論文もあり、再現可能な応用研究の成果となっている。 [MarkTechPost - NVIDIA introduces SpatialClaw, a training-free agent that treats code as the action interface for spatial reasoning](https://www.marktechpost.com/2026/06/19/nvidia-ai-introduce-spatialclaw-a-training-free-agent-that-treats-code-as-the-action-interface-for-spatial-reasoning/), [GitHub - NVlabs/SpatialClaw](https://github.com/NVlabs/SpatialClaw), [SpatialClaw - project page and paper](https://spatialclaw.github.io/)

### Predictions check

本日の動きは、二つの具体的なローカルスタックの状況変化に、コーディングエージェントのガバナンスの一群が重なる構図だ。中心は6月18日にタグ付けされたUnslothのv0.1.47-betaで、マルチトークン予測と組み合わせた新しいauto-fitコンテキストアルゴリズムが、固定メモリ内の実用コンテキストをおよそ3倍にし、32GBのf16 GPU 1枚を超過させることなく約23,040から64,000トークンへ広げる。これが本日最も強いつながりを担い、「企業が2027年第2四半期までに、ホスト型の中国APIではなくオープンウェイトのコードモデルを自前運用する」という予測(6月18日)を関連性4で補強する。各チームが、これまで配信しかできなかった同じMITライセンスのGLM-5.2ウェイトを、自分たちの管理境界内でローカルにファインチューニングできるようになったからだ。回復したvLLM 0.22以降との互換性と、データを自分の境界内に留めることに応えるCloudflare専用の--secure暗号化モードがこれを補い、同じビルドは休眠中の「ローカルのファインチューニングからエージェントへのスタックが、2026年下半期までにマネージドのハイパースケーラーサービスとして登場する」という予測(6月3日)もキーワード一致で復活させる。ただし裏付けるのは軌道であって名指しの目印ではなく、消費者向けクラスの自前運用コンソールが深まった一方で、パイプラインをマネージド階層にまとめたハイパースケーラーはまだ現れていない。二つ目のローカルの状況変化はLiquid AIの350Mオープンウェイト検索ペア(6月19日)で、許諾の緩い高速な多言語リトリーバーが汎用のエッジハードウェアで動くことが、サーバー側の埋め込み呼び出しなしに根拠付き検索を行うオンデバイス部品をそろえる。

三つ目の筋は、コーディングエージェントのハーネスのセキュリティとガバナンスのまとまりだ。Nous ResearchのHermes Blank Slateモードは、ファイル操作とターミナルだけを開き、ウェブ・ブラウザ・コード実行・MCPサーバーなどを明示的に有効化するまでオフに固定する、教科書どおりの最小権限・既定拒否の姿勢である。これが「インラインのMCPチャネルポリシー実施が2027年第1四半期までにプラットフォームの既定として登場する」という予測(6月16日)を関連性3で運び、CiscoのFAPOとCodexのRecord & Replayとあわせて「エージェントのメタハーネスが2027年上半期までにベンダー横断のポリシー基盤になる」という予測(6月15日)も後押しする。ただし、いずれも自社のエージェントだけを統治するハーネスであり、複数の競合ランタイムにまたがって権限とサンドボックス化を一様に適用するベンダー中立のメタハーネスではないという差は残る。NVIDIAのSpatialClaw(6月19日)は、状態を持つPythonカーネルを行動インターフェースとして包み、ステップごとに1つのセルを書いて本物のテスト時計算を行う学習不要のフレームワークで、私のRL/LLM予測性能の予測が頼る、行動としてのコードと推論時の計画見直しのパターンを補強する。先を見据えたカレンダーは、Confidential Computing Summit(6月23〜24日)、AI TinkerersのOffensive Security Demo Night(6月25日)、Snowflake Dev Day(6月25日)、そして推論とセキュリティの専用トラックを持つAI Engineer World's Fair(6月29日〜7月2日)と、近い将来のガバナンスの場を固めている。
