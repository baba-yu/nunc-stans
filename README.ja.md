コーディングエージェントの筋は依存解消の物語だ。Cognitionが6月2日にWindsurfを畳んでDevin Desktopへ移したことで、オープンなAgent Client Protocolが既定のAgent Command Centerの領域として出荷され（Codex、Claude Agent、OpenCode、そしてチーム内製のエージェントをホストし、Rustで書き直されたDevin LocalがCascadeを置き換える）、Microsoftの同日のProject Polaris——自社のMaiaシリコン上で動くMixture-of-Expertsモデル——は8月からGPT-4 TurboをGitHub Copilotの既定エンジンから置き換える。これはMicrosoftとOpenAIの独占関係が4月に終わった数週間後のことだ。これは「オープンハーネスが2社目のベンダーの一次エージェントを動かす」の予測（6月4日）に、オープンコアを独自の領域で包む反転として関連性4で流れ込み、今やエディタとオーケストレーションの層で起きている。これらの筋を結び合わせるのが、Googleの6月3日のApache-2.0のGemma 4マルチモーダル系列と、Unslothの発売初日チューニング（12Bモデルは動的4bit GGUF経由で約8GB、6月5日のQATチェックポイントは下限を約3GB/5GB/7GBへ、26B-A4B MoEを約15GBへ引き下げる）だ。これは「27Bデンス＋1Mコンテキストの企業向けローカルレシピ」の予測（4月23日）と「ローカルのファインチューニングからエージェントまでのスタックがマネージドなハイパースケーラーのサービスとして出荷される」の予測（6月3日）をともに関連性3で復活させ、現行のマルチモーダルなオープンウェイトモデルを発売初日に1枚の民生GPUへ載せる——まさに新しいAI PCが満たそうと作られている、端末側推論の動作範囲だ。NvidiaのN1/N1Xの発売は、「ハイパースケーラーのカスタムシリコンが学習用と推論用に分かれる」の予測（4月22日）も意味的に復活させる。いつものことだが、ここで挙げた到達点——出荷されたサンドボックス化stdioの既定、FARのサイバー表明条項、構文解析で検証されたSELECT専用のSQL許可リスト、マネージドなファインチューニングからエージェントへのコンソール、正式なCIS/OWASPの秘密情報持ち出しの分類——は、いずれも今日の証拠が指し示すにとどまり、まだ実現されてはいない。
