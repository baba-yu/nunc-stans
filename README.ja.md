- **Snowflake が Polaris の双方向書き込みを備えた Iceberg v3 を GA で提供** -- Snowflake Summit 26 のビルダー基調講演(太平洋時間 6 月 3 日水曜午前 9 時、Moscone)で実際に一般提供に至った唯一の成果物が、Polaris の双方向書き込みを備えた Iceberg v3 である。これにより Spark や Trino といった外部エンジンが、統制を適用したオープン標準を通じて、データの重複もダウンタイムを伴う移行もなしに、Snowflake が管理するテーブルへ直接書き込めるようになり、早期採用企業として Affirm と Samsung Ads の名前が挙がった([Futurum - Snowflake Summit 2026: four infrastructure bets that determine whether the agentic enterprise delivers](https://futurumgroup.com/insights/snowflake-summit-2026-four-infrastructure-bets-that-determine-whether-the-agentic-enterprise-delivers/))。基調講演はスライドではなく、ライブの顧客エージェントに話の根拠を置いた。BlackRock は Horizon Context を用いて企業の真実の共有された単一の定義に基づいてエージェントを動かす様子を実演し、Sanofi は医師訪問に向けて営業担当者をライブデータから準備させる「Concierge」というエージェントを示した。同じ週に Sanofi は、AI を活用した創薬の基盤として Snowflake を採用したことも明らかにした([BusinessWire - Sanofi Chooses Snowflake to Accelerate its AI-Powered Drug Development](https://www.businesswire.com/news/home/20260602582503/en/Sanofi-Chooses-Snowflake-to-Accelerate-its-AI-Powered-Drug-Development))。
- **Snowflake が Cortex Sense のオントロジー層をエージェント型データスタックとして位置づける** -- Iceberg v3 の GA に加えて、3 つのプレビュー段階の賭けが Snowflake Summit 26 のエージェント型企業という訴えを支える。Cortex Sense は、統制層 Horizon Context の上に乗り、エージェントが利用するスキルとセマンティクスの共有された定義を自動構築する、メタデータからオントロジーへの層である。Snowflake はこれを MCP と組み合わせた Claude Code より 3.5 倍高い性能だと打ち出すが、本番環境では未実証の数字だと自ら認めている。あわせて、既存の Kafka プロデューサーをコード変更なしで受け入れるフルマネージドの Kafka 互換ストリーミングサービス Snowflake Datastream と、手動チューニングをなくすためにウェアハウスをリアルタイムで自動的にサイズ調整する Adaptive Compute も投入された([Futurum - Snowflake Summit 2026: four infrastructure bets that determine whether the agentic enterprise delivers](https://futurumgroup.com/insights/snowflake-summit-2026-four-infrastructure-bets-that-determine-whether-the-agentic-enterprise-delivers/))。4 つの賭けに通底するのは、統制されたウェアハウスが、単に問い合わせる保管庫ではなく、エージェントがその上で推論する基盤として位置づけ直されている点だ。
