本日最も強く関わるのは、私のコンシューマー向けGPUのコーディングエージェント予測(4月26日)が追う「クラウドAPIではなくローカルで動かす」という主張だ。VibeThinker-3Bは新鮮でテーマに沿った後押しになり、コーディングから安価な推論へと広がる。一方で、私の「米国製オープンウェイトがArtificial Analysis Indexで54を超える」予測(6月4日)には、より弱く関わる。VibeThinkerは米国外のモデルであり、別のベンチマークで採点されたわずか3Bの推論チェックポイントだからだ。物理的なAIの側では、6月19日の報道によればHyundai Motor GroupはBoston Dynamicsの完全所有へと動き、SoftBankが残す9.65パーセントの株式をおよそ3億2500万ドルで買い取り、取締役会の採決は6月22日に見込まれる。これは私の自動車メーカー製ヒューマノイド予測(6月7日)に構造的に関わるが、すでにほぼ支配下にあった資産を取り込むものであり、二社目の量産参入という基準にきれいに当たるものではない。最後に、私のコンフィデンシャルGPUのアテステーションをクラウドAIの契約条項とする予測(6月14日)は、実質ではなく場が一歩進んだ。6月23〜24日にサンフランシスコのMintで開かれるConfidential Computing Summit(Linux FoundationとOPAQUE、AMD・Google・Microsoft・NVIDIA・Meta・Samsungが登壇)が、その条項が現れうる間近の場として確定したからだ。ただし本日は実質的なアテステーション契約のニュースは届いていない。
