- **AWS、ニューヨーク・サミットでエージェント基盤に業務コンテキストとAI駆動の脆弱性サービスを追加** — AWSはニューヨーク・サミット(6月17日開催、報道は週末まで続いた)で、企業向けエージェントを阻む要因を「業務コンテキストの欠如」と「セキュリティの欠如」と位置づけ、両方を狙う2つのサービスを発表した。AWS Contextは、既存のデータベース・文書・メール・チャットと業務ルールからガバナンスの効いたナレッジグラフを自動構築し、社内のどのエージェントでも実行時に問い合わせられる検索レイヤーとして提供する。アクセス制御が組み込まれ、エージェントは呼び出し元に許可された範囲しか見られない。AWS Continuumはモデル非依存の脆弱性管理サービスで、発見・優先順位付け・検証・提案の4段階を回し、サンドボックス内で実際に動く攻撃コードを構築して問題が本物だと証明し誤検知を取り除く。攻撃経路の推論にはClaude Mythosを含むフロンティアモデルを活用し、金融・自動車・テクノロジー各業界のパイロット顧客とともに限定プレビュー段階にある。あわせてBedrock AgentCoreには、エージェントの動作をプロンプトインジェクション・有害コンテンツ・機微データ露出について審査するGuardrails、数百のセッションを横断する最適化分析、Check Point・Zscaler・SentinelOne・Netskope・Rubrikからの検知シグナル(提供予定)が加わった。提供状況や機能に関する主張はAWS自身によるものだ。 [AWS - 2026年ニューヨーク AWS サミットの主要発表](https://aws.amazon.com/blogs/aws/top-announcements-of-the-aws-summit-in-new-york-2026/), [AWS セキュリティブログ - AWS Continuum の紹介: マシンスピードのセキュリティ](https://aws.amazon.com/blogs/security/introducing-aws-continuum-security-at-machine-speed/), [About Amazon - 2026年 AWS ニューヨーク・サミット: AI エージェントを職場でより役立たせる新しい方法](https://www.aboutamazon.com/news/aws/aws-summit-nyc-2026-ai-agents)
- **OpenAI、有益特性を強めるRLを少量混ぜるとモデルが全般的に安全になり操作されにくくなると報告** — OpenAIは6月19日、研究「Reinforcement Learning Towards Broadly and Persistently Beneficial Models」を公開し、創発的なミスアライメントの背後にあるのと同じ汎化のしくみを逆方向にも向けられると論じた。医療・教育・科学・法律・工学にまたがる現実的な会話を題材に、誠実さ・認識上の謙虚さ・是正可能性・推論の透明性・公平性・人間の幸福への配慮という6つの目標特性を強化学習で強める。重要なのは、この有益特性のデータをごく一部だけ、それ以外は通常どおりのRLポストトレーニング工程に織り込んだ点だ。訓練したモデルは、欺瞞・正直さ・追従・報酬ハッキング・健康に関する挙動を測る53の独立したベンチマークのうち44で改善し、効果は分野を越えて汎化した。見出しになるのは2つの頑健性の発見だ。1つは「選択的持続性」で、ベースラインを不安定にした敵対的プロンプトの効果が訓練後は明らかに弱まった。もう1つは、悪意あるファインチューニングが植え付けた特性を侵食しにくくなった一方、正当な指示には依然柔軟に従えた点で、ジェイルブレイクおよびファインチューニング攻撃への耐性を直に押し上げる。OpenAIは本手法をAnthropicの明示的な憲法方式とは別物と位置づけ、予備的な結果で再現が待たれる自社数値だと注意を促している。 [OpenAI - 広範かつ持続的に有益なモデルへ向けた強化学習](https://alignment.openai.com/beneficial-rl), [OpenAI - Reinforcement Learning Towards Broadly and Persistently Beneficial Models（PDF）](https://cdn.openai.com/pdf/beneficial-rl.pdf), [The Decoder - 有益特性の訓練を少量加えると AI モデルが全般的に安全になり操作されにくくなることを OpenAI の研究者が示す](https://the-decoder.com/openai-researchers-show-small-doses-of-beneficial-trait-training-make-ai-models-broadly-safer-and-harder-to-manipulate/)
- **OpenAIの新ベンチマークLifeSciBench、最良モデルでも実際のライフサイエンス研究タスクの約3分の1しか解けず** — OpenAIは、バイオテクノロジーと製薬の現場の博士号レベルの科学者173名とともに構築した、ライフサイエンス研究向けの750タスクからなるベンチマークLifeSciBenchを公開した(関連報道は6月20日まで続いた)。タスクは自由記述形式で、平均約25項目の専門家作成ルーブリック(合計およそ19,020項目)に照らして採点され、多くはゲノム配列ファイルや化学構造ファイル、実験データといった実際の科学的成果物の解釈を求める。評価された最良モデルであるOpenAIのGPT-Rosalindが正解できたタスクは約36.1%にとどまった。最も示唆的なのは成果物の壁で、正答率はテキストのみのタスクでの45.1%から、ファイルやURLの解釈が必要になると28.1%へ落ち込み、設計・最適化・多段階分析のタスクも約30%しか解けなかった。これは自律研究エージェントの具体的な上限を示すものだ。モデルは科学を語れても、現場の科学者が実際に扱うデータオブジェクトの解析でつまずく。OpenAIが自ら執筆し自社のGPT-Rosalind更新と同時に公開したベンチマークである以上、その枠組みやスコアはベンダーのものであり外部の精査を招く。 [MarkTechPost - OpenAI が LifeSciBench を公開、実際のライフサイエンス研究で AI モデルを採点する750タスクのベンチマーク](https://www.marktechpost.com/2026/06/17/openai-releases-lifescibench-a-750-task-benchmark-grading-ai-models-on-real-life-science-research-with-expert-written-rubric/), [OpenAI - GPT-Rosalind の新機能を紹介](https://openai.com/index/introducing-new-capabilities-to-gpt-rosalind/), [Labcritics - LifeSciBench: OpenAI の手強い新ライフサイエンス・ベンチマークと GPT-Rosalind の実力](https://labcritics.com/blog/2026/06/19/lifescibench-openais-hard-new-life-science-benchmark-and-how-gpt-rosalind-stacks-up/)
