半導体の筋は、予測群そのものの起点となった出来事の直接の続きであり反転だ。6月8日の反発（Intel 約8.5%、Micron 約9%、前週金曜の約1兆ドルの売り崩しから回復）は、市場関係者が金曜の下落を流動性主導と呼んだことで「AIアクセラレータ株が次の市場予想どおりのASIC決算で一段安に再評価」の予測（6月7日）の高すぎるハードルという仕組みを裏づける一方、市場予想どおりの新たな約定が再び押し下げたわけではない反転であり、将来の発火には決め手を欠く。同じ変動の大きいタイミングは「計算資源の見立てに基づくIPO供給がAI株の混雑を生む」の予測（6月4日）が注視するSpaceXの価格決定の内側に収まるが、月曜の急反転と価格決定そのものの読みの不在で混雑は観測でなく示唆にとどまる。「Nvidiaの目標株価平均が300ドルを超える」の予測（6月6日）はNvidiaの18A評価というファウンドリ側の言及のみで、データセンター需要の仕組みとは無関係に進む。同じ国内ファウンドリへの移行——AlphabetがIntelに約300万個を委託し、Nvidiaが18Aを評価——は「カスタムAIシリコンの学習対推論SKU分化」の予測（4月22日）を、まさにカスタムでマーチャント外のシリコンの話題として再点火させたが、文字どおりの学習対推論の分割には一歩届かない。いつものとおり、名指しされた各到達点は本日の証拠が指し示すにとどまり、まだ実現されてはいない。
