- **Apple が Private Cloud Compute を Google Cloud の機密 Blackwell GPU 上で実行** — Apple は、プライバシーを強化した推論基盤である Private Cloud Compute を拡張し、Apple 管理外のデータセンターとして初めて Google Cloud 上で動かすことを明らかにした。Apple Foundation Models のサーバー側推論は、NVIDIA Blackwell GPU 上の機密コンピューティングモードで実行される。NVIDIA は6月9日の投稿で、このセキュリティモデルを、本物で改ざんされていない GPU 上のハードウェアに根ざした信頼に、暗号化された通信経路とリモートアテステーションを加えたものと説明した。これにより、機密データを送る前にインフラを暗号学的に検証できる。この構成は、Blackwell の機密コンピューティングを、Intel TDX CPU および Google の Titan セキュリティチップと組み合わせている。Apple は信頼境界を握り続ける。暗号学的な台帳が Google Cloud の全ノードを追跡し、すべての PCC バイナリは検査のために公開され、Security Bounty もホスト先ノードに及ぶ。この展開は2026年夏のプレビューを通じて段階的に拡大し、さらに詳しい内容は6月23〜24日の Confidential Computing Summit で示される見込みだ。 [NVIDIA Blog - NVIDIA Confidential Computing to help expand Apple's Private Cloud Compute](https://blogs.nvidia.com/blog/nvidia-confidential-computing-apple-private-cloud-compute/), [Apple Security Research - Expanding Private Cloud Compute](https://security.apple.com/blog/expanding-pcc/), [Help Net Security - Apple extends Private Cloud Compute to Google Cloud](https://www.helpnetsecurity.com/2026/06/10/apple-private-cloud-compute-google-cloud-expansion/)
- **新ベンチマーク EvoArena、エージェントは世界の変化につれてずれていくと判明し、スコアは39.6%** — 6月の arXiv 論文2本が、エージェントとは何かを捉え直し、その持ちこたえ方を検証している。『Agentic Software: How AI Agents Are Restructuring the Software Paradigm』（arXiv:2606.05608）は、LLM エージェントはソフトウェアの根本的な再構成だと論じる。コードがあらかじめ書かれた判断ロジックを担うのではなく、エージェント自身がソフトウェアであり、その判断ロジックは実行時に生成される。これはライセンス販売型ソフトウェアから SaaS、そして agent-as-a-service への移行だという。実証面では、EvoArena（arXiv:2606.13681、6月11日）が、環境が段階的な更新を通じて変化していく中で、エージェントが知識の整合を保てるかどうかを、ターミナル・ソフトウェア・ソーシャルの各領域で検証する。現行のエージェントの成績は振るわず、平均正答率は39.6%にとどまる。著者らは EvoMem を提案している。これはメモリを構造化された更新履歴として記録するパッチ方式のメモリ手法で、EvoArena を平均1.5%引き上げつつ、GAIA と LoCoMo をそれぞれ6.1%、4.8%改善したと報告されている。これにより、静的なベンチマークは長時間動作するエージェントの頑健さを過大評価する、という指摘がいっそう鮮明になっている。 [arXiv - Agentic Software: How AI Agents Are Restructuring the Software Paradigm](https://arxiv.org/abs/2606.05608), [arXiv - EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments](https://arxiv.org/abs/2606.13681)
