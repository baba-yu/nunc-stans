### News

- **Naglabas ang Nvidia ng unang consumer PC silicon nito sa loob ng isang dekada: ang Arm-based na N1/N1X** — Sa Computex sa Taipei noong June 1, inilantad ni Jensen Huang ang N1 at N1X, ang unang consumer-class na PC processor ng Nvidia sa loob ng mahigit isang dekada at isang tuwirang pagpasok sa client market na hawak ng Intel, AMD at Qualcomm. Ang mga chip ay Arm system-on-chip na may integrated RTX/CUDA GPU cores: ang flagship na N1X ay nagpapares ng 20-core (10+10) CPU sa 6,144 CUDA cores sa 45-80W, samantalang ang standard na N1 ay nagpapatakbo ng 10- at 12-core CPU config na may 2,048-2,560 CUDA cores sa 18-45W, ayon sa TechSpot at PCWorld. Ibinalangkas ng Nvidia ang launch kasabay ng Microsoft bilang "isang bagong panahon ng PC" na may agentic AI na tumatakbo nang lokal, at ang mga laptop ay ipapadala sa taglagas mula sa Microsoft (Surface), Dell, HP, ASUS, Lenovo at MSI, ang ilan ay kasing-nipis ng 14mm. Ang istratehikong pagbasa ay sinusubukan ng Nvidia na ariin nang sabay-sabay ang bawat layer ng AI stack - mga data-center accelerator, ang lisensyadong Groq inference IP, at ngayon ang on-device inference layer sa Windows-on-Arm na laptop - na nagpababa sa shares ng AMD, Intel at Qualcomm sa araw na iyon at ginagawang isang first-party na edge-LLM runtime ang consumer laptop. [TechSpot - Nvidia's first consumer CPU in over a decade is coming, and it has RTX cores built in](https://www.techspot.com/news/112585-microsoft-nvidia-arm-tease-new-era-pc-computex.html), [PCWorld - Nvidia's RTX Spark chip 'reinvents' laptops for agentic AI](https://www.pcworld.com/article/3152460/nvidia-rtx-spark-chip-reinvents-laptops-for-agentic-ai.html)

- **Naging pinaka-nakalantad na AI surface ang MCP: 67 CVE, gabay ng NSA, leak sa Ollama** — Nagtagpo ang AI-agent security ngayong linggo sa iisang konklusyon - ang Model Context Protocol na nag-uugnay ng mga agent sa mga tool ay naging pinaka-nakalantad na bahagi ng stack. Sa isang roundup noong June 4, itinampok ng Adversa AI ang VIPER-MCP, isang static-and-dynamic taint-analysis framework na sumaklaw sa humigit-kumulang 40,000 MCP server repository, naglabas ng 106 zero-day at nagbunga ng 67 CVE (siyam mula sa sirang OAuth flow); binanggit ng parehong review ang isang Censys scan na nagbilang ng 12,520 internet-accessible na MCP service, karamihan ay hindi naka-authenticate, kung saan humigit-kumulang 40% ng remote server ang naglalantad ng mga tool nang walang anumang auth. Inihayag ng Akamai ang tatlong database-MCP na depekto (SQL injection sa Apache Doris, hindi-authenticated na metadata exfiltration sa Alibaba RDS, at isang takeover path sa Apache Pinot), at inilathala ng NSA ang "Model Context Protocol: security design considerations for AI-driven automation," na nagngangalan sa inverted client-server pattern, hindi-beripikadong task propagation at arbitrary-code-execution bilang pangunahing panganib; pinakamataas-bigat ang tool-poisoning dahil ang malisyosong server metadata ay pumapasok sa konteksto ng agent na may awtoridad sa antas ng instruksyon bago pa man ang anumang pagsusuri ng tao. Sa panig naman ng hilaw na imprastruktura, inilarawan ng mga mananaliksik ang "Bleeding Llama" (CVE-2026-7482, CVSS 9.1), isang heap out-of-bounds read sa GGUF loader ng Ollama na nagpapahintulot sa isang hindi-authenticated na umaatake na makapag-leak ng process memory - mga API key, system prompt, mga usapan ng ibang user - mula sa tinatayang mahigit 300,000 na nakalantad na server, na inayos sa Ollama 0.17.1, ayon sa The Hacker News. [Adversa AI - Top MCP security resources & CVEs June 2026](https://adversa.ai/blog/top-mcp-security-resources-june-2026/), [SecurityWeek - Top 25 MCP vulnerabilities reveal how AI agents can be exploited](https://www.securityweek.com/top-25-mcp-vulnerabilities-reveal-how-ai-agents-can-be-exploited/), [The Hacker News - Ollama out-of-bounds read vulnerability allows remote process memory leak](https://thehackernews.com/2026/05/ollama-out-of-bounds-read-vulnerability.html)

- **Humihiwalay ang mga coding agent sa mga vendor: Devin Desktop at ang Polaris ng Copilot** — Muling nag-ayos ang coding-agent tier noong unang bahagi ng Hunyo sa paligid ng dalawang hakbang tungo sa kalayaan mula sa provider. Noong June 2, inretiro ng Cognition ang Windsurf brand sa pamamagitan ng isang over-the-air na update na muling nagbukas sa editor bilang Devin Desktop - na muling itinayo mula sa isang editor na may nakadikit na AI tungo sa isang agent manager na nakabalot sa isang buong IDE, kung saan ang Agent Command Center ang default na harapan at may suporta para sa bukas na Agent Client Protocol (ACP), kaya ang Codex, Claude Agent, OpenCode at anumang ibang ACP-compatible na agent (kasama ang in-house na agent ng isang team) ay maaaring tumakbo sa loob nito; isang Rust-rewritten na lokal na agent, ang Devin Local, ang humahalili sa dating Cascade engine, at inilalarawan ang ACP bilang inampon na ng JetBrains, Google, GitHub at mahigit 25 na agent, ayon sa Cognition at Devin. Sa parehong araw sa Build 2026, inilantad ng Microsoft ang Project Polaris, ang unang in-house na coding model nito - isang mixture-of-experts na sistema na tumatakbo sa sariling Maia silicon ng Microsoft at papalit sa GPT-4 Turbo bilang default na engine para sa bawat GitHub Copilot subscriber simula Agosto (awtomatikong migration, opsyonal na tatlong-buwang fallback), na ipinapadala kasama ng isang multi-agent na VS Code, ayon sa TechTimes. - **Naglabas ang Gemma 4 nang multimodal at open-weight; tina-tune ito ng Unsloth sa unang araw sa ~8GB RAM** — Inilabas ng Google ang Gemma 4 noong June 3 bilang isang Apache-2.0 open-weight na pamilya na likas na humahawak ng teksto, larawan at audio nang walang hiwalay na encoder network, at ang Unsloth - ang local fine-tuning at inference optimizer na sinusubaybayan sa bawat run - ay naglabas ng suporta sa unang araw para sa pagpapatakbo at pag-tune nito sa consumer hardware. Ang praktikal na epekto para sa local-LLM at edge-runtime na track ay ang isang kasalukuyang multimodal open-weight model ay tina-tune at naiha-serve na ngayon sa iisang consumer GPU sa mismong araw na inilabas ito, na siyang eksaktong on-device inference envelope na dinisenyong punuin ng bagong alon ng AI PC.
