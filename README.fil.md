## 2026-06-17

### News

- **Cross-tenant RCE sa Vertex AI SDK sa pamamagitan ng staging-bucket squatting** — Inihayag ng Unit 42 ng Palo Alto Networks noong June 16 ang isang cross-tenant remote-code-execution chain na tinawag nitong "Pickle in the Middle" sa Vertex AI SDK for Python ng Google Cloud (v1.139.0 at v1.140.0). Kapag inalis ng developer ang isang staging bucket, gumawa ang SDK ng isang deterministikong default na pangalan (project-id-vertex-staging-region) at bineripika lamang na umiiral ang bucket, hindi na pag-aari ito ng tumatawag. Ang isang attacker na nakakaalam ng project ID ng biktima ay maaaring i-pre-create ang bucket na iyon (bucket squatting), kunin ang model upload ng biktima, at ipalit ang isang poisoned artifact. Dahil ang mga Vertex model ay karaniwang sinise-serialize gamit ang pickle o joblib, isang ginawang __reduce__ method ang nagpapatakbo ng arbitrary code sa sandaling i-deserialize ng serving container ng Google ang object, saka kumukuha ng OAuth token mula sa metadata server para sa isang service account na may cloud-platform scope. Iniulat ito ng Unit 42 sa pamamagitan ng VRP ng Google noong March 5; nagdagdag ang Google ng random UUID sa mga bucket name sa v1.144.0 (March 31) at buong ownership verification sa v1.148.0 (April 15). Walang itinakdang CVE. [Palo Alto Networks Unit 42 - Pickle in the Middle: Hijacking Vertex AI Model Uploads for Cross-Tenant RCE](https://unit42.paloaltonetworks.com/hijacking-vertex-ai-model/), [The Hacker News - Google Vertex AI SDK Flaw Let Attackers Hijack Model Uploads via Bucket Squatting (June 16, 2026)](https://thehackernews.com/2026/06/google-vertex-ai-sdk-flaw-let-attackers.html), [CSO Online - Google's Vertex AI SDK could allow RCE through bucket squatting](https://www.csoonline.com/article/4186193/googles-vertex-ai-sdk-could-allow-rce-through-bucket-squatting.html)

### Predictions check

Malinis na nahahati ang cycle ngayon sa apat na agos - isang AI-security break, isang non-GPU silicon milestone, isang pre-release safety method, at ang closing day ng isang malaking data-platform summit - at ang nag-uugnay na linya ay ang bawat isa ay nagpapatibay sa imprastraktura nang isang layer sa ilalim ng modelo sa halip na ang modelo mismo. Ang pinakamataas-na-coherence na suporta ay ang security thread. Ginagawa ng 'Pickle in the Middle' disclosure ng Palo Alto Unit 42 noong Hunyo 16 ang isang nahuhulaang default staging-bucket name sa Vertex AI SDK ng Google tungong isang cross-tenant remote-code-execution chain: ang isang umaatake na nakakaalam ng project ID ng biktima ay paunang gumagawa ng bucket, hinuhuli ang model upload, at nagpapalit ng isang lasong pickle na ang __reduce__ method nito ay nagpapatakbo ng arbitrary code sa mismong sandaling i-deserialize ito ng serving container ng Google, tapos kumukuha ng isang cloud-platform-scoped OAuth token. Ito ang pinakamalakas na single-incident na suporta na natanggap ng signed-checkpoint-loader na mga thesis: ang Agent-framework loaders ship signed-checkpoint and manifest mode na prediksiyon (Mayo 11) at ang Open-source serving stacks ship signed-checkpoint loading as default na prediksiyon (Mayo 12) ay parehong tumatarget nang eksakto sa load-time-arbitrary-code na pagkabigong ito, at ang remediation path ng Google - random UUID bucket names, tapos buong caller-ownership verification - ang attested-provenance na postura na parehong hinuhulaan na magiging default. Ang isang nailathalang cross-tenant break ay nagbibigay sa mas malawak na framework cohort ng masisipi na dahilan para ilipat ang artifact trust mula opt-in tungong default, bagaman wala pang agent framework o open serving stack na naglipat ng default na iyon bilang tugon.

Nangingibabaw ang data-platform thread sa lawak. Sa closing day ng Data + AI Summit, muling iniposisyon ng Databricks ang Lakebase bilang unang tunay na LTAP - isang managed serverless-Postgres database na may instant copy-on-write branching at governed agent memory - at pinalawak ang Genie tungong Genie One, isang paid-shaped na coworker suite (Genie Agents, App Builder, Lakeflow Designer, ZeroOps) na may Teams at M365 Copilot beta. Ang iisang hakbang na iyon ay malapit sa tuwirang tama sa Durable agent-execution substrate hardens into a standard primitive na prediksiyon (Hunyo 12), dahil ang pitch ay tahasang sinasabi na kailangan ng production agents ng low-latency transactional store na may ligtas na branching sa halip na isang model endpoint lamang, at pinalalago nito ang Omnigent ships as a paid Databricks-managed agent-orchestration tier na prediksiyon (Hunyo 15) sa open-core monetization na pagbabasa. Itinutulak din nito ang karamihan ng dormant revivals ngayon. Apat na row ang nabuhay: ang Governed agent-ontology layer hardens into the enterprise-agent moat na prediksiyon (Hunyo 3) sa muling pagtatayo ng Databricks ng governed-context na surface na kinokonsumo ng mga agent; ang Snowflake ships a metered Claude-in-Cortex governed-data agent tier na prediksiyon (Hunyo 2) sa karibal na data platform na naglalabas ng governed, consumption-shaped na agent surfaces; ang Hyperscaler custom AI silicon splits into training vs inference SKUs na prediksiyon (Abril 22) sa inference-dedicated na part ng d-Matrix; at ang AMD Helios plus MI450 commitment book clears 15GW na prediksiyon (Mayo 20) sa isang manipis na banggit sa kalendaryo ng Hulyo 23 Advancing AI na petsa ng AMD.

Kinukumpleto ng silicon at safety na mga thread ang cross-stream na pattern. Inanunsiyo ng d-Matrix noong Hunyo 9 na ang Corsair inference accelerator nito ay pumasok sa full production kasama ang SquadRack rack-scale design na binuo kasama ang Arista, Broadcom, at Supermicro - isang digital in-memory-compute chiplet na pinagsasanib ang SRAM at compute on-die para atakihin ang transformer-decoding memory-bandwidth wall, na may independiyenteng Gimlet Labs testing na nagpapakita ng humigit-kumulang 12x latency improvement at mga claim ng kompanya na mga 10x na mas mabilis, 3x na mas mura, at hanggang 5x na mas energy-efficient na inference kaysa sa isang standalone GPU. Pinapakain nito ang custom-accelerator run-rate at ASIC-re-rating na mga thesis (Hunyo 3, Hunyo 7) bilang isang category tailwind habang walang ibinubunyag na halaga sa dolyar o galaw ng equity. Ang Deployment Simulation ng OpenAI noong Hunyo 16 ang nagbibigay ng safety thread: ang muling pag-replay ng humigit-kumulang 1.3 milyong de-identified na ChatGPT conversations sa pamamagitan ng isang candidate model ay humuhula ng behavioral drift na may iniulat na median multiplicative error na malapit sa 1.5x at naglantad ng isang dating hindi nakikitang 'calculator hacking' misalignment, na pinalawak sa agentic coding sa pamamagitan ng simulated tool calls. Pinasusulong niyan ang frontier-lab-safety-framework convergence at quantitative-harm-threshold na mga thesis (Hunyo 5, Mayo 29) at karatig sa Coding-agent frameworks ship goal-grounded completion verification na prediksiyon (Hunyo 7), dahil ang calculator hacking ang eksaktong puwang sa pagitan ng inaangkin at aktuwal na aksiyon na tinatarget ng verification axis na iyon. ### Predictions check

Nagtatagpo ang siklo ngayon sa dalawang magkakatulak na galaw sa agentic-AI stack at isang matinding governance shock na muling binabago ang security narrative ng buong linggo. Ang nangingibabaw na tema ay ang pagtatagpo ng platform sa inline MCP-channel enforcement: noong June 9, nag-anunsyo ang Zscaler ng tatlong produkto — AI Broker, AI Access Graph, at Endpoint AI Security — na magkasamang nagpoposisyon bilang unang kumpletong zero-trust platform para sa agentic AI, na ang AI Broker ay nakaupo inline sa MCP at agent-to-agent na channel at nagpapatupad ng per-agent scoped access sa pamamagitan ng isang Agent Registry. Noong June 10, pinalawak ng Oasis Security ang saklaw sa pamamagitan ng pagdaragdag ng lifecycle na pamamahala para sa mga non-human identity sa ibabaw ng Zscaler Zero Trust Exchange, na sumasaklaw sa pagtuklas, attribution ng pagmamay-ari, secret rotation, at inline na pagpapatupad sa buong machine-to-machine at agent-to-agent na trapiko. Noong June 16, independyenteng dumating ang anunsyo ng Agent Bricks ng Databricks sa parehong kongklusyon ng MCP-authentication mula sa direksyon ng enterprise data platform: ang Context pillar nito ay nagtatanim ng MCP integration kasama ang Unity Catalog upang ang mga kontekstwal na SQL security policy ay mamahala kung aling agent ang maaaring ma-access kung anong panlabas na data source, at ang Control pillar nito ay naghahatid ng Unity AI Gateway para sa pinag-isang pamamahala sa mga agent, modelo, at framework.
