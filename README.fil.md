- **Natuklasan ng bagong benchmark na EvoArena na lumihis ang mga agent habang nagbabago ang kanilang mundo, na nagmarka ng 39.6%** — Muling binabalangkas ng dalawang arXiv paper noong June kung ano ang mga agent at sinusubok kung gaano sila katibay. Argumento ng Agentic Software: How AI Agents Are Restructuring the Software Paradigm (arXiv:2606.05608) na ang mga LLM agent ay isang pundamental na muling pagbuo ng software: sa halip na code na may dalang nakasulat nang lohika ng pagpapasya, ang agent mismo ang software at ang lohika ng pagpapasya nito ay nililikha habang tumatakbo, isang paglipat mula sa lisensyadong software tungo sa SaaS tungo sa agent-as-a-service. Sa panig na empirikal, sinusubok ng EvoArena (arXiv:2606.13681, June 11) kung nananatiling magkatugma ng mga agent ang kaalaman nila habang nagbabago ang kapaligiran sa pamamagitan ng mga sunod-sunod na update sa mga domain ng terminal, software at sosyal; mahina ang mga kasalukuyang agent, na nag-aaverage ng 39.6% na katumpakan. Iminumungkahi ng mga may-akda ang EvoMem, isang patch-based na paradigm ng memory na nagtatala ng memory bilang mga istrukturadong kasaysayan ng update, at iniulat nilang itinataas nito ang EvoArena nang 1.5% sa karaniwan habang pinapabuti ang GAIA at LoCoMo nang 6.1% at 4.8% - na nagpapatalas sa natuklasang labis na ipinapalagay ng mga static na benchmark kung gaano talaga katibay ang mga matagal na tumatakbong agent. [arXiv - Agentic Software: How AI Agents Are Restructuring the Software Paradigm](https://arxiv.org/abs/2606.05608), [arXiv - EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments](https://arxiv.org/abs/2606.13681)
