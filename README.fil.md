- **Pinaputok sa wild ang cross-tenant IDOR ng Langflow (CVE-2026-55255)** — Iniulat ng Threat Research Team ng Sysdig noong June 25 ang unang kilalang in-the-wild na pananamantala sa CVE-2026-55255, isang cross-tenant na insecure-direct-object-reference na depekto sa Langflow, ang open-source na visual builder para sa mga LLM agent. May rating na CVSS 9.9 at naayos sa 1.9.1, ang bug ay nasa get_flow_by_id_or_endpoint_name: ang isang flow na niresolba gamit ang UUID ay walang isinasagawang owner check, kaya maaaring patakbuhin ng sinumang authenticated user ang flow ng ibang tenant sa pamamagitan ng /api/v1/responses (CWE-639). Nakita ng Sysdig na inani ng isang operator ang mga flow ID mula sa GET /api/v1/flows/ at niwagi ang mga ito mga dalawampung segundo ang lumipas sa POST /api/v1/responses gamit ang input na 'leak api keys', laban sa isang instance na nagpapatakbo rin ng KEV-listed na RCE na CVE-2026-33017. Dapat mag-upgrade na ngayon ang mga operator ng anumang pre-1.9.1 Langflow at ipalagay na inaani na ang mga nakalantad na flow ID. [Sysdig - Understanding Langflow CVE-2026-55255, and why higher-CVSS vulnerabilities aren't always the most exploited](https://webflow.sysdig.com/blog/understanding-langflow-cve-2026-55255-and-why-higher-cvss-vulnerabilities-arent-always-the-most-exploited), [GitHub Advisory Database - Langflow IDOR in /api/v1/responses lets authenticated attackers run another user's flow (CVE-2026-55255)](https://github.com/advisories/GHSA-qrpv-q767-xqq2)

- **Naglalantad ng mga internal na serbisyo ang SSRF-protection bypass ng AutoGPT (CVE-2026-56663)** — Inilathala noong June 26 bilang CVE-2026-56663 ang isang high-severity na depekto sa AutoGPT, ang open-source na platform para sa pagbuo at pagpapatakbo ng tuluy-tuloy na AI agent. May rating na CVSS 8.5 at naayos sa 0.6.52. Nilulusutan nito ang mga server-side-request-forgery na proteksyon ng AutoGPT: hindi nahahawakan nang tama ng SendWebRequestBlock na ginagamit ng mga agent para sa mga outbound na HTTP call ang mga IPv4-mapped na IPv6 address at nabibigo itong i-validate ang ilang IP range, kaya makakabuo ang isang authenticated user ng isang request na lumulusot sa internal-IP filter at umaabot sa mga serbisyo sa private network. Dahil ang nagkaproblemang block ay isang general-purpose na fetch primitive na nakakabit sa mga agent workflow, maaaring maakay ang agent ng isang tenant para suriin ang cloud metadata, internal admin panel, o database na hindi dapat maabot. Dapat mag-upgrade ang mga operator na mas mababa sa 0.6.52 at limitahan ang outbound egress mula sa agent runner. [NVD - CVE-2026-56663 Detail (AutoGPT SSRF-protection bypass via IPv4-mapped IPv6 addresses, fixed in 0.6.52)](https://nvd.nist.gov/vuln/detail/CVE-2026-56663)

- **Naglulupon ang Feast ML feature-store ng unauthenticated RCE sa pamamagitan ng gRPC registry deserialization** — Inilathala noong June 24 bilang CVE-2026-56121 ang isang maximum-severity at unauthenticated na remote-code-execution na depekto sa Feast, ang open-source na machine-learning feature store, na may rating na CVSS 9.3 (v4.0) at naayos na sa Feast 0.63.0. Kapag pinoproseso ng registry server ang isang gRPC request, dini-decode nito mula sa base64 ang field na user_defined_function.body ng isang OnDemandFeatureView spec at direktang ipinapasa ito sa dill.loads() bago ang anumang authorization check, kaya makakapagsumite ang isang umaatake ng isang ginawang serialized Python object na may arbitrary na __reduce__ method at makakapagpatakbo ng OS commands bilang ang Feast service account nang walang credential. Ang structural na pagbasa ay bumaba ang ML attack surface nang isang layer mula sa model at inference engine papunta sa data-and-metadata plumbing: ang isang registry na tumatanggap ng serialized transformation logic sa network ay isang unauthenticated na code-execution endpoint maliban kung naka-gate ang deserialization. Dapat ituring ng mga operator na nakalantad ang anumang pre-0.63.0 deployment na may network-reachable na gRPC registry, mag-upgrade agad, at tiyaking hindi maa-address ang registry mula sa mga untrusted network.
