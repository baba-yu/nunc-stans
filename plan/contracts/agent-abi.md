# Agent ABI Contract

Status: Reserved

This defines the ABI for registering, starting, stopping, and mandate-checking resident programs, agents, schedulers, butlers, and tool workers.

For now this is reserved only.

## Reserved Scope

- agent identity
- fixed version reference
- mandate reference
- startup check
- suspension / revocation check
- run log
- output reference

## Rule

A resident program does not run without a commitment + mandate + fixed version reference.
