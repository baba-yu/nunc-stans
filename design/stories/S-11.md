# S-11 — The agent remembers only with permission (Phase D)

In a terminal I start `nunc-stans-agent chat` under a profile with a
local model; the agent answers with streaming and visible thinking,
reads and writes memory only through manda within its mandate and
refuses a write outside it; the run appears in the run log. (v1 plan
§4, verbatim.)

manda is the **local checkout's release build** via `MANDA_BIN` until
the owner tags v0.2.0 (plan PD8); the manda data dir is scratch and the
agent is its only writer (PD9). NB: in manda, proposals always land in
the candidate lane (no authority); **the refusal point is
`memory_commit`** — that is what "refuses a write outside it" pins.

Setup:

    export NS_DATA=$(mktemp -d)         # scratch store, bootstrapped
    export MANDA_DATA_DIR=$(mktemp -d)  # scratch memory, one writer
    export MANDA_BIN=~/manda/target/release/manda
    # a profile for the agents context: provider ollama, qwen3.6:27b
    # grant ONE scoped mandate by hand (the agent only PRINTS the line):
    nunc-stans-agent mandate-template 'notes/*' | tail -1 \
        >> $MANDA_DATA_DIR/mandates.jsonl

Pass (mechanical):

    nunc-stans-agent chat            # picks the `agents` default profile
      → banner shows profile id + model; startup mandate check lists
        the notes/* mandate (with expiry) — and shows a readable
        "no active mandate" state when mandates.jsonl is empty
      → a question streams the answer with a visible thinking pane

    # in-mandate write: propose → interactive approval → committed
    ask the agent to remember a fact under notes/
      → propose lands (candidate lane), the ELICITATION prompt appears
        in the terminal, approving commits it
    $MANDA_DATA_DIR/committed.jsonl  → the record carries
                                       "origin_verified": true
    ask the agent to recall it       → memory_read surfaces it (≤ 3)

    # out-of-mandate write: the commit is REFUSED, denial surfaced
    ask it to remember something under drafts/ (no mandate)
      → propose lands, commit is refused; the agent SHOWS the denial
        ("no active write mandate …"), does not retry silently
    declining the elicitation prompt also denies (nothing committed)

    # F3: the constitutional rail fires before manda is even asked
    ask it to write a self-scope commitment
      → refused by the agent itself, names F3 / user-only

    tail -1 $NS_DATA/runs/ai-runs.jsonl → the chat run row: caller
        nunc-stans-agent, profile stamp, provider ollama, token counts

Acceptance is the permission mechanics + streaming surfaces; local-model
answer quality is not gated (structural acceptance). Evidence (terminal
transcript incl. the refusal and the elicitation prompt, the committed
record, the ai-runs row) → design/verification/phase-d.md.
