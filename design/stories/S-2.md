# S-2 — Commit from a world headline (Phase-3 behavior under the new shell)

From a world headline I create a commitment; the `informed_by` edge is
attached automatically and the F9 provenance line on home updates
(constitution §10-C-3). First proven in Pre-v1 Phase 3; re-verified under
the Phase B shell (gate + router + cold world view).

Setup: scratch vault (`NS_DATA=<scratch>`, `self/` git-initialized, no
remote), `NEWS_WORLD` set so headlines exist, `just up`.

Steps:

1. Note the provenance line on home (e.g. `0/1 ... (0%)`) and the edge
   count from `curl -s :8720/self/edges`.
2. Open World, pick a headline, "Commit from this headline", author it
   (user peer).
3. The row reports `authored self/commitment/<slug> + informed_by → News
   (provenance updated)`.
4. `/self/edges` count +1 (the new edge targets `world/prediction/<id>`,
   author `user`); home's provenance line moves (the new commitment is
   AI-prompted).

Pass: the response line in step 3 and both step-4 observations.
First executed: Phase B close (see design/verification/phase-b.md).
