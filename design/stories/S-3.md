# S-3 — Pick your pair (Phase C)

The owner opens the World view's news settings drawer, switches the
pipeline from `claude-code`/native search to a **local model + external
search engine** (ollama `qwen3.6:27b` + brave), and the next daily run
(against the sandbox instance — the pipeline never touches the real
`~/news`, per the plan's 2026-07-06 redirection) completes with that
pair — provenance recorded, no config file edited by hand. The same
drawer switches it back.

Pass (mechanical):

    # the drawer round-trips through the one door
    curl -s :8720/api/world/news-config
        → current JSON (runtime/search/searchEngine/synthProvider/synthModel)
    PUT via drawer: search=external, searchEngine=brave,
        synthProvider=ollama, synthModel=qwen3.6:27b
    curl -s :8720/api/world/news-config      → the switched pair
    cat <data store>/world/news-config.json  → same JSON (atomic file)

    # the pipeline honors it without flags
    nunc-fluens run --date <D>               → exits 0
    app/sourcedata/<D>/run.json              → mode=live, runtime=ollama,
                                               search=brave,
                                               synth_model=qwen3.6:27b
    <data store>/runs/ai-runs.jsonl          → per-call rows name the pair

Acceptance is structural validity of the produced day (schemas + gates
green), not content quality (C4). Switch-back leaves the next run on
claude-code/native, recorded the same way. Evidence (drawer screenshots,
both run.json files) → design/verification/phase-c.md.
