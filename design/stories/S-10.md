# S-10 — Pristine environment (re-run at every phase close)

On a pristine Ubuntu (container or fresh WSL distro): clone → bootstrap →
up → home screen, with no steps beyond the documented prerequisites
(git, Node ≥ 24 + corepack, rustup, just — exactly what `just bootstrap`
doctors). From Phase B: also on native Windows. At Phase F: the same run
additionally passes `just journey`. The 3-OS CI matrix stays green
throughout.

Pass: `curl http://127.0.0.1:8720/health` answers from the pristine
environment after `git clone` + `just bootstrap <dir>` + `just up` (the
data store designated by bootstrap, remembered by the app config — no
environment variable involved).

Phase D extension: the bootstrap doctor reports the **manda** state —
`ok manda (…)` when installed (or `MANDA_BIN` points at a build), else
the instructive miss with the real install line
(`cargo install --locked --git https://github.com/baba-yu/manda --tag
v0.2.0`). manda is needed for agent memory, not for the home screen, so
a missing manda is informative, never a bootstrap failure.
First executed: Phase A close (see design/verification/phase-a.md).
