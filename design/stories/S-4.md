# S-4 — Nothing up my sleeve (Phase C)

With the network unplugged from the model's point of view — no LLM, no
search — the pipeline replays an already-published day from its committed
sourcedata and reproduces the exact published world: same reports, same
dashboard, same DB effect. The published artifacts alone are sufficient
provenance; nothing depends on a conversation that can't be rerun.

Pass (mechanical), on a pristine sandbox copy of the news checkout with
a clean working tree (the real `~/news` is never a run target — plan
redirection 2026-07-06):

    nunc-fluens run --date <published D> --replay   → exits 0
        (the AI layer is null in replay — no call path exists; any step
         reaching for a provider is a hard failure, not a skip)

    git -C <newsRepo> status --porcelain
        → ONLY app/sourcedata/<D>/run.json (new or modified)

    Allowed run.json diffs (the complete list):
        mode="replay", started_at / finished_at timestamps,
        per-step durationMs, step status "replayed"/"ok"

    report/, future-prediction/, README*.md, references.txt, docs/
        → byte-untouched (zero lines in git status)
    sqlite3 <data store>/world/analytics.sqlite 'PRAGMA integrity_check'
        → ok

Sunday days replay the weekly chain too (dormant snapshot, theme review,
maintenance artifacts verified + integrity-gated). Substrate proven on
goldens at T6: weekday 2026-06-27 and Sunday 2026-06-28 replay to
byte-identical renders and the exact golden DB state. Evidence (command
log + git status output) → design/verification/phase-c.md.
