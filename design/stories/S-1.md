# S-1 — One origin (Phase B)

With `just up` running: http://127.0.0.1:8720 reaches home (ME); the topbar
reaches World and Timeline with no port change; the FourFive tab opens
/fourfive/ whose API answers through the same origin; every surface speaks
the nunc-ui language (shared topbar idiom + tokens).

Pass (mechanical), all against :8720:

    curl -s /health              → {"engine":"nunc-stans-engine",...}
    curl -s /gate/health         → {"gate":"nunc-stans-gate",...}
    curl -s /fourfive/api/health → {"ok":true,"provider":...}
    curl -s /                    → contains <title>Nunc Stans</title>
    curl -s /fourfive/           → the FourFive app HTML
    curl -s /timeline            → the app HTML (SPA fallback, 200)

plus a visual pass over home / world / timeline / fourfive.
