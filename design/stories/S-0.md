# S-0 — Cold start on this machine

From a clean checkout with no data store configured, reach the home screen
in at most 3 steps (workspace model: the user designates a folder, the app
remembers it).

1. `just bootstrap <folder-of-your-choice>` → ends with "bootstrap ok"
   (folder created + initialized + remembered in the app config)
2. `just up` — no environment variable needed → engine serves on :8720
3. Open http://127.0.0.1:8720 → the home screen renders (an empty state is
   fine)

Pass: all three succeed with no undocumented step.
Test isolation note: when executing on a machine with a real config, run
both commands under `XDG_CONFIG_HOME=<scratch>` so the real setting is
untouched — that exercises the identical code path.
