# S-0 — Cold start on this machine

From a clean checkout and an empty NS_DATA, reach the home screen in at most
3 commands.

1. `NS_DATA=<fresh dir> just bootstrap` → ends with "bootstrap ok"
2. `NS_DATA=<fresh dir> just up` → engine serves on :8720
3. Open http://127.0.0.1:8720 → the home screen renders (an empty state is
   fine)

Pass: all three succeed with no undocumented step.
First executed: Phase A close (see design/verification/phase-a.md).
