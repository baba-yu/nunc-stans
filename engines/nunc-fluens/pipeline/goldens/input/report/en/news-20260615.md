1. Cached-rollout agent fine-tuning reaches a second open framework by H1 2027

   The June 12 arXiv paper CacheRL (arXiv:2606.14179) attacks the most expensive part of teaching a small model to use tools well: reinforcement learning over multi-turn tool use normally has to run the real tools live thousands of times per training batch, which dominates cost and makes the loop slow and brittle. CacheRL removes the live tool calls by replaying a three-tier fuzzy cache of past trajectories with token-level masking, and pairs that with a cache-tier-aware hybrid reward that reweights answer quality so the model is not punished for gaps the cache itself introduced. The reported numbers are the kind that get a method copied rather than admired: 92% process accuracy on multi-step tool-calling, within striking distance of GPT-5's reported 94%, while using roughly 100x less compute, and lifting validation reward on Qwen3-4B-Thinking from 0.43 to 0.78, with ablations crediting a 17% gain to the cache-aware reward.
