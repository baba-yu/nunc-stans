### New arxiv work proposes WorldEvolver: self-evolving world models that update at inference time to sharpen LLM-agent planning

- A paper submitted to arXiv on June 29, <a href="https://arxiv.org/abs/2606.30639">"Self-Evolving World Models for LLM Agent Planning" by Xuan Zhang, Wenxuan Zhang, See-Kiong Ng and Yang Deng</a>, targets a concrete failure mode in agent harnesses: agents plan badly because they predict the consequences of their actions badly. The proposed framework, WorldEvolver, improves that action-outcome prediction through three coupled components — an episodic memory that recalls past interactions, a semantic memory that distills explicit rules from prediction errors, and a selective-foresight mechanism that filters out unreliable predictions before they reach the planner. The notable design choice is that the world model keeps evolving during deployment while the core agent stays frozen, so the system adapts at inference time without retraining the backbone. The authors report the highest prediction accuracy across three different backbone models and higher downstream task-success rates than competing world-model baselines on interactive environments, which positions runtime memory updates as a cheaper lever for agent reliability than full fine-tuning — relevant to the orchestration and coding-agent harnesses that increasingly depend on accurate forward simulation. [arXiv - Self-Evolving World Models for LLM Agent Planning (2606.30639)](https://arxiv.org/abs/2606.30639)
