## Future


1. キャッシュ再生によるエージェント・ファインチューニングが2027年H1までに第二のオープンフレームワークへ到達する

   6月12日に公開された arXiv 論文 CacheRL(arXiv:2606.14179)は、小型モデルにツールの上手な使い方を教えるうえで最も費用のかかる部分に切り込む。マルチターンのツール利用に対する強化学習では、通常、学習バッチごとに実際のツールを何千回もライブで実行する必要がある。これが費用の大半を占め、学習ループを遅く、壊れやすいものにしている。CacheRL はこのライブのツール呼び出しを取り除く。過去の試行(トラジェクトリ)を三層のあいまいキャッシュに蓄え、トークン単位のマスキングを施して再生するのだ。さらにこれを、キャッシュの階層を踏まえたハイブリッド報酬と組み合わせる。この報酬は回答品質の重み付けを調整し、キャッシュ側が持ち込んだ欠落を理由にモデルが罰せられないようにする。報告された数値は、感心して眺めるより手法ごと真似されるたぐいのものだ。マルチステップのツール呼び出しでプロセス正答率92%を記録し、GPT-5 の報告値94%にあと一歩まで迫りながら、計算量はおよそ100分の1で済む。さらに Qwen3-4B-Thinking の検証報酬を0.43から0.78へ引き上げており、アブレーションによればそのうち17%分はキャッシュを踏まえた報酬の寄与だとされる。これが広がる構造的な理由は、取り除かれるボトルネックが普遍的だという点にある。オープンモデルでエージェント RL を行う全チーム、そして主要なオープンな学習後ライブラリ群(TRL、verl、OpenRLHF、SkyRL、ART、NeMo-RL)や推論に結合したロールアウト基盤も、同じライブのツール実行コストを支払っている。キャッシュ再生方式のロールアウトに階層を踏まえた報酬を添えたものは、新しいモデルアーキテクチャではなく、ロールアウト段階をそのまま差し替える部品である。まさにこれは速く普及するたぐいの技法の形だ。先を見据えた本予測の中核は、キャッシュ再生型(ライブ実行の代わりに再生する)のツール呼び出しエージェント向け RL が、一本の論文から、実務者が既製品として手に取れる正式な学習モードへと固まっていくという点にある。具体的で反証可能な実現条件は次のとおり。2027年H1(2027年6月30日まで)に、次のいずれかが成立すること。第一に、CacheRL 著者ら自身のコード以外の主流のオープンなエージェント RL または学習後フレームワーク(TRL、verl、OpenRLHF、SkyRL、ART、NeMo-RL、あるいは同程度に普及したオープンライブラリ)が、マルチターンのツール呼び出し RL 向けに、キャッシュまたは再生ロールアウトモード(ライブのツール実行に代えたマスキング付きのオフライン・トラジェクトリ再生)の文書化された第一級サポートを出荷すること。第二に、少なくとも一つの独立したグループが、別のベースモデル系列にキャッシュ再生型 RL を適用してオープンウェイトまたは学習コードを公開する再現を発表し、フロンティアモデルとの差が10ポイント以内のツール呼び出し正答率を、一桁低いロールアウトコストで報告すること。該当しないものは次のとおり。文書化されたキャッシュ再生のロールアウト経路を伴わず、単に「より安いエージェント RL」を謳うだけのクローズドまたはホスト専用サービス。RL のロールアウトループではなく推論のみに使う、一般的なプロンプトまたはトラジェクトリのキャッシュ。出荷された機能や公開された成果物を伴わない、CacheRL への引用・ベンチマーク言及・ブログでの参照。あるいは同じコードベース上での原著者による続報。2027年6月30日の時点で、キャッシュ再生型 RL が原典の CacheRL 論文とその自前リポジトリにとどまり、第二のフレームワーク機能も、別モデルでの独立したオープンな再現も存在しない場合、この予測は外れとなる。


   In plain language: 新しい手法は、実際のツールを動かし直す代わりに過去の実行を再生することで、ツールを使う AI を100倍安く学習させる。まもなく他の学習キットもこれを真似る。

### ローカル LLM 最適化の研究:キャッシュ再生型 RL のレシピが、小型のツール呼び出しエージェントをわずかな計算量でフロンティア精度へ向けて学習

- 6月12日の arXiv 論文 CacheRL: Multi-Turn Tool-Calling Agents via Cached Rollouts and Hybrid Reward(arXiv:2606.14179)は、小型エージェントモデルのファインチューニングにおける実務上のボトルネックに取り組む。マルチターンのツール利用に対する強化学習は、通常、費用のかさむライブのツール実行を要する。CacheRL は代わりに、トラジェクトリの三層のあいまいキャッシュをトークン単位のマスキングを施して再生し、ライブの呼び出しを避ける。そしてこれを、キャッシュの階層を踏まえたハイブリッド報酬と組み合わせる。この報酬は回答品質の重み付けを動的に調整し、キャッシュ自身が持ち込んだ制約を理由にモデルが罰せられないようにする。著者らは、マルチステップのツール呼び出しのタスクでプロセス正答率92%を報告し、GPT-5 の報告値94%に迫りながら、計算量はおよそ100分の1だとする。さらに Qwen3-4B-Thinking の検証報酬を0.43から0.78へ引き上げており、アブレーションでは、知識転移を除くと41%低下し、キャッシュを踏まえた報酬が17%分寄与するとされる。これは、費用のかさむライブ実行の RL ループなしに、ツール呼び出しの能力を小型のオープンモデルへ蒸留する具体的なレシピである。 [arXiv - CacheRL: Multi-Turn Tool-Calling Agents via Cached Rollouts and Hybrid Reward](https://arxiv.org/abs/2606.14179)
