## Summary of Findings

本日のサイクルには、単一の決定的な出来事はない。代わりに、その一貫性は一つのテーマ、すなわち最大手クラウドの外で AI を動かす経済性に沿って走り、3つの新規予測のそれぞれがそこに旗を立てている。最も濃密な技術的兆候は7月1日に公開された Ollama 0.31 で、Apple Silicon 上の Gemma 4 でマルチトークン予測をデフォルトで有効化し、出力はバイト単位で同一のまま、コーディングエージェント向けベンチマークでトークン生成がほぼ90%高速化したと報告する。加えて、上流へ還元された小バッチ向け MLX 行列積カーネルは、M5 Max と nvfp4 の環境で Gemma 4 の最大級の行列積を2〜2.5倍高速化し、Gemma 専用ではなく任意の MLX モデルで再利用できる。これは新規予測「ローカル LLM ランタイムがモデル内蔵の投機的デコードをデフォルトで有効にして出荷する」（7月5日）の起点となる証拠だ。関連度は最大となる。チューニング用フラグではなくデフォルトとして出荷されること、そしてコーディングエージェントが予測しやすいコードに対してモデルを絶えず呼び出すため、採用されたドラフトの効果がセッションを通じて積み上がることが理由だ。同じリリースは、「量子化をデフォルトとするサービングが OSS 推論の基準線として着地する」という仮説（6月30日）をローカルランタイムの側から鮮明にし、Claude Code と opencode の自動インストールフックを通じて「公開当日の vLLM/SGLang と Ollama 対応がオープンウェイトの公開条件になる」という規範（7月2日）を補強し、オンデバイスとホスティングの差をまさにその仮説が生きる場所で縮めることで、休眠していた「コンシューマー GPU のコーディングエージェントが開発者の30%についてクラウド専用 API を置き換える」というロングショット（4月26日）を復活させる。残る隔たりは率直だ。2つ目の主流ローカルランタイム、すなわち LM Studio、llama.cpp のデスクトップ版、MLX-LM、あるいは vLLM のローカルモードは、投機的デコードをまだデフォルト経路に切り替えていない。

2つ目の支柱となる筋は、資本が AI スタックを一段下り、オープンモデル推論の層へ移っていることであり、これもまた一つの新規予測を支えている。Together AI は7月1日、ポストマネー評価額83億ドルで8億ドルのシリーズCを発表した。2025年2月のラウンドから2.5倍の評価額上昇であり、NVIDIA、Vista、General Catalyst が参加するなか Aramco の Prosperity7 が主導した。DeepSeek、Nemotron、MiniMax、Kimi をクローズドモデルのごく一部のコストで提供するネオクラウドである同社を、主導投資家は株式公開へ向かうものと位置づけた。これは新規予測「オープンモデル推論のネオクラウドが上場に向けた一歩を提出する」（7月5日）の起点となる証拠であり、「OpenAI が米国政府の出資を伴って上場に向けた一歩を提出する」という背景（7月4日）に同じ方向のデータ点を加え、休眠していた「フロンティア AI 研究所が公開の S-1 を提出し IPO の価格を決める」というロングショット（6月12日）を市場ウィンドウのレベルで復活させる。いまやそれは推論の層で見え、各研究所自身の IPO への引力と地続きのものとして描かれている。欠けているのは、投資家の見解ではなく、具体的に開示された一歩、すなわち秘密保持または公開の S-1 だ。

3つ目の筋は、非 GPU シリコンの層が独自のカテゴリーとして名指され資金を得ていることであり、同一サイクル内で互いを補強する2つの兆候を通じて、一つの新規予測と一つの復活を担っている。Stathera は6月30日、応募超過となった5500万ドルのシリーズBを完了した。MediaTek と TXC が参加するなか Maverick Silicon が主導し、目的は明確に AI データセンター向けクロックの GEN3 プラットフォームへの出資であり、加速器クラスターが数万 GPU 規模に達するなか、MEMS DualMode タイミングを2030年までに累計およそ15億ドルの同期需要機会として売り込んでいる。並行して、Tenstorrent の Jim Keller は、報じられた80〜100億ドルの Qualcomm による買収を公に否定し、独立した IPO ブリッジと秘密保持 S-1 の路線を改めて表明して、信頼に足る RISC-V 加速器 IP 企業を、モバイル SoC の既存大手へ吸収されるのではなく単独で保った。両者を併せると、これは新規予測「非 GPU の AI データセンターシリコンが独立系インフラ資金を引き寄せる」（7月5日）の起点となる証拠であり、Tenstorrent の側面だけでも、「2つ目のハイパースケーラーが非 Nvidia のデータセンター推論シリコンを名指す」という仮説（6月29日）、「推論 ASIC 群が4つ目の名指された買い手設計チップを得る」という仮説（6月25日）、そして昨日の「2つ目のオープンウェイトのフロンティアモデルが非 NVIDIA ASIC での学習を開示する」という予測（7月4日）に、商用の非 NVIDIA 供給の層を生かし続けることで触れつつ、休眠していた「Tenstorrent の S-1 が3社の AI チップ IPO 群の先陣を担う」というロングショット（5月24日）を意向と路線のレベルで復活させる。本日を締めくくると、イベントカレンダーは AMD の MI400 Instinct シリーズと Helios ラックスケールシステムを、Geneva AI Week（7月6〜10日）と Hot Chips（8月23〜25日）の後ろにある後半の一般的な注視対象へと押し戻す。したがって「AMD Instinct MI400 が名指された出荷、メモリ、ラックの仕様を伴って登場する」（6月27日）と「AMD MI400 がピーク FLOPS よりメモリ帯域を前面に打ち出す」（7月2日）はいずれも、第3四半期のウィンドウが狭まるなか、確定した近い将来の枠から後退する。


## Relation to My Own Predictions
