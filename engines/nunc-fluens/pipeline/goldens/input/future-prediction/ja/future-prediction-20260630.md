ユーザーの 1 つ目の継続予測(マルウェアとしての悪意あるローカル LLM と、根本的な安全策としてのゼロトラスト)は、本日は方向性のあるインフラレベルの接触にとどまり、その中核の軸に新たな基盤は得られなかった。最も近いシグナルは、Microsoft Foundry における Azure ホスト型の Claude 一般提供とともに搭載された NVIDIA の Secure Agent Workspace 参照設計である。これは GB300 NVL72 シリコン上で稼働し、自律的かつ領域特化のエージェントを企業の ID・ネットワーク・課金・ガバナンス統制の内側に位置づける。これはこの仮説が追う構造的な答えである、統制されたエージェント実行への収束だが、推論の立ち上げに同梱されたベンダーの参照設計であって、名前を持つ認証プリミティブではない。署名付きチェックポイントもテナント単位の能力ゲート機構もなく、エージェントワークフローの CVE の波もなく、MCP サーバーの隔離テレメトリもなく、連邦や同盟国の調達強制条項も出ていない。この仮説が立脚する既定拒否の認証の論拠は、それ自体の条件では前進しなかった。本日はハイパースケーラーとベンダーが統制されたエージェントへ向かう枠組みの圧力を供給する一方、認証・CVE テレメトリ・調達ゲートの軸は未決のままである。

ユーザーの 2 つ目の継続予測(高度・フロンティアの作業にはクラウド API、日常用途にはローカル LLM、SaaS の値上げが牽引)は、本日最も強い両面の基盤を得る。高度なクラウドの極では、Claude Opus 4.8 と Haiku 4.5 が、Azure ホスト型の GB300 NVL72 上で Microsoft Foundry 内の一般提供に到達し、Azure の請求書で一本化して課金され、NVIDIA が GB300 の推論効率を総保有コストの削減要因として打ち出している。これはまさに、この仮説が高度なワークロードをハイパースケーラー規模に固定し続けると見込む、ハイパースケーラー基盤上のフロンティアの統合である。日常のローカルの極では、vLLM v0.24.0 の Model Runner V2 が量子化モデルを既定とし、GPU メモリを超えてキャッシュを退避させる多階層 KV キャッシュオフロードに加え 180〜290% の SM90 CUTLASS FP8 高速化を備えることで、低精度を既定とする重みと階層化 KV 退避を、主流のオープンソースサーバーにおいて任意設定のチューニングから文書化された既定値へと動かす。これは、この仮説が汎用推論をデバイス上に引き寄せると述べるローカル LLM の計算余地を広げる。本日は、SaaS の直接的な値上げや消費者向け GPU のリリースという裏付けがなくとも、この二分化の両極を直接的に強化する。フロンティア推論は統制されたハイパースケーラーのシリコンへ統合され、一方でローカル配信スタックのメモリ下限は下がる。

ユーザーの 3 つ目の継続予測(RL/LLM ベースの予測性能の向上に、MoE 基盤・ガバナンス・現実世界の展開の堅牢化が並行)は、その基盤とガバナンスの軸で意味のある接触を得る。Xuan Zhang、Wenxuan Zhang、See-Kiong Ng、Yang Deng による WorldEvolver 論文が最も直接的なシグナルである。推論時に自己進化する世界モデルが、エピソード記憶、誤差から蒸留した意味規則、選択的予見によって行動と結果の予測を改善し、世界モデルは展開中に適応し続ける一方でバックボーンは固定されたままで、3 つのバックボーンにわたって最高水準の予測精度を示す。これはまさに、自律的な予測エージェントが必要とする実行時に適応する予測の機構であり、全面的な RL 微調整より安価なてこである。MoE 基盤の軸では、vLLM v0.24.0 がエキスパート並列のために DeepEP v2 を統合し、DeepSeek-V4 のスパースインデックスとプリフィル計画の最適化を実施したことで、この仮説が前提とする Mixture-of-Experts のバックボーン提供が、主流を占める推論サーバーにとって既定経路で活発に扱われる関心事であることを裏付ける。ガバナンスの軸は、自律エージェントを中心とする NVIDIA の Secure Agent Workspace の監査と認証の枠組みから、この仮説が追う調達の境界という考えに弱い構造的な裏付けを得る。ただし署名付きスキルレジストリの相互運用も、NIST の制御プロファイルの基準点も、物理 AI の生産ループの閉路も出ていない。本日は基盤とハーネスの軸が前進した一方、形式的なガバナンスと現実世界の展開の証明は後日に残されている。
