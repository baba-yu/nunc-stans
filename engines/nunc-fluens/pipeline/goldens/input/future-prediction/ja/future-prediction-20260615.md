## Summary of Findings

本日の動きは異例なほど整合的だ。同じエージェント基盤の構築という3つの軸が、いずれもモデルそのものではなく、モデルの一段上の層へと引き寄せられている。中心となる出来事は、Databricks が6月13日に公開した Omnigent だ。これは Apache 2.0 のアルファ版のオープンソースのメタハーネスで、個々のコーディングエージェントやエージェント SDK の一段上に位置し、開発者が複数を一つのインターフェースから動かせるようにする。コマンドラインのエージェント（Claude Code、Codex、Pi）と SDK（OpenAI Agents、Claude Agents SDK）を束ね、実装を書き換えずに入れ替えられる。構造上の要となる細部は、ガードレールがどこに置かれるかである。Omnigent はメタハーネスの層そのもので、状態を保持し文脈に応じたポリシーを適用する。束ねた各エージェントの動作を追跡し、その下にどのランタイムがあろうとも、コスト上限、権限、OS レベルのサンドボックスを横断的に課す。ライブセッションは URL で共有でき、チームメンバーが同じ実行を確認し、コメントし、方向づけられる。クラウド実行は Modal と Daytona のサンドボックス上で行い、複数ハーネスのエージェントは YAML で記述する。これは Databricks 限定の機能ではなく、Data + AI Summit に合わせて出荷された独立した GitHub プロジェクト（omnigent-ai/omnigent）だ。この単一のリリースが、本日の新しい予測の大半を支える。1つは、メタハーネスが H1 2027 までにエンタープライズのエージェントのベンダー横断のポリシー面になるという予測である（その要となる主張は、統一された操作の入り口ではなく、統治がベンダー中立な制御点へと上がっていくことだ）。もう1つは、Omnigent 自身が Q2 2027 までに、価格の付いた Databricks ホスト型のマネージド階層として出荷されるという予測で、オーケストレーションを無償で配ってランタイムで収益化するオープンコアの筋書きに乗る。これは Databricks 自身の Spark と Delta の歴史からそのまま読み取れる筋書きだ。

ローカルモデルの軸は、6月12日の arXiv 論文「CacheRL: Multi-Turn Tool-Calling Agents via Cached Rollouts and Hybrid Reward」（arXiv:2606.14179）だ。これは、小さなエージェントモデルのファインチューニングで最も費用のかかる部分に切り込む。複数ターンのツール利用に対する強化学習は通常、学習バッチごとに実際のツールを何千回も実際に動かさねばならない。CacheRL はこれを、過去の軌跡を3階層のファジーキャッシュとして、トークン単位のマスキングを伴って再生することで、実呼び出しを回避する。あわせてキャッシュ階層を考慮したハイブリッド報酬を用い、回答品質の重み付けを調整して、キャッシュが持ち込む制約でモデルが不当に減点されないようにする。報告された数値は、感心される類ではなく模倣される類だ。複数段のツール呼び出しでプロセス正答率92%（GPT-5 の報告値94%に対して）を、おおむね100分の1の計算量で達成し、Qwen3-4B-Thinking の検証報酬を0.43から0.78へ引き上げる。アブレーションでは、知識転移を外すと41%低下し、キャッシュ考慮の報酬で17%向上すると報告している。切り込んだボトルネックが普遍的で、キャッシュ再生が新しいアーキテクチャではなくロールアウト段階をそのまま差し替えるだけであることから、本日の新しい予測は普及を見込む。すなわち、2つ目の主流のオープンな事後学習ライブラリ（TRL、verl、OpenRLHF、SkyRL、ART、NeMo-RL）がキャッシュ再生を一級の機能として出荷するか、別のベースモデルでの独立した再現が H1 2027 までに現れるか、である。今のところ、この手法はまだ単一の論文と自前のリポジトリに限られている。

ユーザーの1つ目の標準的な予測（悪意あるローカル LLM がマルウェアになること、そして根本的な防御策としてのゼロトラスト）は、本サイクルで新たな攻撃や CVE は見られないものの、構造的な防御の軸で予期せぬ方向からの具体的な補強を得る。脅威の領域ではなく制御の領域からだ。Databricks が6月13日に公開した Omnigent は、メタハーネスの層そのもので状態を保持し文脈に応じたポリシーを適用し、束ねた各ランタイム（Claude Code、Codex、Pi、OpenAI Agents、Claude Agents SDK）に対して、エージェントごとのコスト上限、権限、OS レベルのサンドボックスを横断的に課す。これは、ゼロトラストの軸が名指す「基盤を決して信頼しない」姿勢を、出荷されたベンダー中立な基本部品にしたものだ。あらゆるエージェントの動作を、ランタイムごとに信頼するのではなく、単一の適用点で仲介し、観察し、制約する。CacheRL は兵器化の軸に対するより静かな隣接だ。複数ターンのツール呼び出しの能力を、小さなオープンモデル（Qwen3-4B-Thinking）へおおむね100分の1の計算量で蒸留するレシピは、自律的にツールを使うエージェントを立ち上げる敷居を下げる。これはこの主張が見守る両用の能力であるが、悪意あるツールの事案ではなく、無害な学習手法の成果である。この軸が追う連邦の執行と証明の手段は、本日のところ先を見据えた場として並ぶだけだ。すなわち、6月23〜24日のサンフランシスコ造幣局での Confidential Computing Summit（機密エージェントと安全な AI ワークフローがテーマ）、Black Hat USA の AI Summit、11月5〜6日の OWASP Global AppSec USA、そしてユーザーが注視する Zenity AI Agent Security Summit の2026年グローバルシリーズである。したがって本日は、ゼロトラストの基盤を実際のランタイム横断のポリシー適用層で強固にする一方、調達の関門と署名済みの証明の軸は議題として控えたままに残す。
