本日の証拠群は、3 つのまとまりに最も強い裏付けを積み上げており、いずれのまとまりも新規の予測を中心に据えている。最も密度の高い圧力のシグナルは、Cato AI Labs が Cursor のコーディング IDE で公開した、CVSS 9.8 のゼロクリックのサンドボックス脱出の欠陥 2 件である。いずれも Cursor 3.0 で修正済みで、一つは任意の working_directory パラメータを介したパストラバーサル、もう一つはシンボリックリンク解決のフォールバックであり、エージェントが取り込むよう設計された内容、すなわち汚染された README、Web 検索結果、あるいは MCP ツールの応答が、承認の確認を経ずにワークスペースの外への任意の書き込みへと変わってしまう。この単一の開示は、2 つの予測に同時に最大の関連度で当たる。一つは、この開示が起点の証拠となる「コーディング IDE がワークスペースに閉じたエージェントのファイル書き込みをデフォルトにする」という新規の予測であり、もう一つは「エージェントビルダーのフレームワークが MCP ツール実行をデフォルトでサンドボックス化して出荷する」という見立てである。後者については、先の Flowise と Langflow の開示の背後にある、ホスト権限で動く同じツール実行境界の破綻を、ニッチなローコードビルダーから、開発者が日々信頼できないリポジトリに対して動かす旗艦の editor へと移すものだ。両者に残る欠落は同じで、率直なものである。RCE は圧力を証明するが、デフォルト拒否・正規パス・シンボリックリンク拒否のワークスペース封じ込めを常時のデフォルトとして出荷した主流の editor は、まだ一つもない。

オープンウェイトの軸が本日の 2 つ目の要となるシグナルであり、これもまた新規の予測を支える。Meituan の LongCat-2.0 は、トークンあたりの有効パラメータがおよそ 48B、ネイティブで 100 万トークンの文脈を持つ 1.6 兆パラメータのエージェント型コーディングの mixture-of-experts で、6 月 30 日に MIT ライセンスで公開され、NVIDIA GPU を一切介さず 5 万基を超える中国製 ASIC 上で端から端まで構築・提供され、Owl Alpha として匿名の 2 か月を OpenRouter の世界トップ 3 で過ごしたのち SWE-bench Pro で GPT-5.5 を 59.5 対 58.6 で上回った。これは、新規の「第 2 のオープンウェイトのフロンティアモデルが非 NVIDIA の ASIC 学習を開示する」という予測を支える実在証明である。同じ公開が、オープンウェイトをめぐる一連の予測に裏付けを放射している。信頼できる最上位クラスの自己ホスト可能なチェックポイントを GitHub と Hugging Face に置くことで「企業がホスティングされた中国 API より自己ホストのオープンウェイトのコードモデルを選ぶ」を強め、Qwen、DeepSeek、Mistral 3 の参照群と並ぶことで「公開時点での vLLM/SGLang と Ollama の対応がオープンウェイトの公開基準になる」を補強し、オープンウェイトの同等性の仕組みを介して 4 つの休眠中の見立て、すなわち Terminal-Bench 2.1 の 85 超の目標、サブ 7B の検証済み AIME の基準、単一の 24〜32GB GPU での長文脈の微調整の軌道、そして本日の並行する Cursor の悪用の証明を介した AWS-Continuum のサンドボックスでの悪用検証のパターンを復活させる。ここで収束するのは、米国が制限するシリコンを使わずに構築された一つのフロンティア間近の学習が、計算資源からの独立、自己ホスト、オープンウェイトの能力という各領域を同時に動かすという点である。

3 つ目のまとまりは資本の集中であり、これもまた新規の予測に加えて復活を担う。Crunchbase の上半期の集計は、世界のベンチャー資金が過去最高の 5,100 億ドルに達し、OpenAI と Anthropic だけで 2,170 億ドル、すなわちベンチャー資金全体の 43% を吸収し、Q2 には 32 社のベンチャー支援企業が 10 億ドル超の評価額で株式公開し、OpenAI が計画中の公開デビューに先立ち米政府におよそ 5% の出資枠を打診した、と報じている。これは新規の「OpenAI が政府出資を伴う上場の一歩を提出する」という予測の直接の背景であり、休眠していた「フロンティア AI ラボが公開 S-1 を提出して IPO の価格を決める」という大穴を土台の水準で復活させ、Menlo が Anthropic 株を土台に過去最大の調達を完了したのと同じ週に位置する「Menlo Ventures が 30 億ドルの調達を専用の AI ファンドのビークルへ投じる」の要となる前提を裏づける。本日を締めくくるものとして、Anthropic の Claude Enterprise のコスト統制の機能、すなわち組織・チーム・部門の各単位の支出上限、モデル単位の権限、利用状況の分析ダッシュボード、エージェントの労力の制御、そして企業のトークン浪費に対して打ち出されたリアルタイムの支出アラートは「エージェント型コーディングのプラットフォームがトークンの予算と上限をデフォルトで出荷する」にほぼ直撃する。さらに、7 月 22〜23 日の AMD の Advancing AI の基調講演は、確定した日付と名称のある Helios ラックシステムを公開待ちとして、MI400 の 2 つの予測をともに着地の姿勢に置いている。


## Relation to My Own Predictions

標準の予測群に対して、本日はエージェントセキュリティの軸が支配的であり、本日の新規の分野横断の予測が位置するのもここである。Cursor のゼロクリック RCE 2 件は、ここ数週間で最も鋭いエージェントスタックの土台である。引き金が、承認を経ずにワークスペースの外への任意の書き込みを引き起こす取り込み内容であるため、これは、エージェントのスタックが攻撃者の操る文字列をホストアクセスへと変える場が、モデルではなくツール実行境界だという論拠を固め、Flowise の stdio の開示から主流の editor へとこのパターンを広げる。この単一の出来事が、標準の予測の一連の列を一挙に押す。ワークスペースに閉じたファイル書き込み、デフォルトでサンドボックス化された MCP 実行、デフォルト無効の stdio トランスポート、テナント単位のフロー認可、そして三点セットの権限ゲートである。一方で、Anthropic が組み合わせた HackerOne の報奨金とベンダー横断のジェイルブレイクの深刻度評価の枠組みは、情報開示が堅牢化を促すという対になる要素を与える。まだ現れていないのは、実際に出荷されたデフォルトである。デフォルト拒否・正規パスのワークスペース封じ込めを常時の挙動にした editor もフレームワークもまだなく、したがって圧力は決定的だが、仕組みは依然として先にある。

オープンウェイトと計算資源からの独立の軸は、久しぶりに最も強い新しい土台を得ており、本日の 2 つ目の新規の予測はこの上に直接築かれている。Meituan の LongCat-2.0 は、中国製 ASIC 上で端から端まで学習・提供されつつ SWE-bench Pro で GPT-5.5 を上回る、フロンティア間近の MIT ライセンスのコーダーであり、単一の実在証明を再現可能なひな型へと変え、供給が制限された体制の内側のあらゆるラボに同じ輸出規制の圧力を及ぼす。これはまさに、新規の非 NVIDIA 学習の予測が、第 2 の、独立して開示される学習へと延ばしていく軌道である。同じチェックポイントは、企業が外国のエンドポイントに通す代わりに自社内に取り込める最上位クラスのオープンウェイトのコーダーを手渡すことで、ホスティングされた API より自己ホストという論拠を傾け、難しいコーディング・推論・1 枚差しの微調整のベンチマークにまたがる、休眠していたオープンウェイトの同等性の見立てを復活させる。この軸全体で欠けているのは、自らの端から端までの非 NVIDIA の学習を記録した第 2 の独立したモデルカードであり、したがって方向は証明されている一方、確定は保留のままである。

資本市場の軸は、新規の予測が着地する 3 つ目の場であり、本日は異例なほど手厚く裏付けられている。Crunchbase の上半期の集計、すなわち OpenAI と Anthropic がベンチャー資金全体の 43% を取り込んだ過去最高の 5,100 億ドルの上半期、再び開いた出口の窓、そして計画中のデビューに先立ち OpenAI が米政府におよそ 5% の出資枠を打診したことは、新規の政府出資を伴う上場の予測の直接の背景である。同じ集中の読みが、休眠していたフロンティアラボの S-1 の大穴を復活させ、Menlo Ventures の専用ビークルの見立ての前提を裏づける。構造的な読みは、これほど極端な集中を私募の巨額ラウンドで示し続けるのは難しく、これがこのセクターの基軸を、政府出資の構造をまとった公開市場での流動性へと向かわせるというものである。この軸全体でいまだ欠けているのは、具体的に提出された一歩、すなわち S-1 や F-1、正式な上場発表、あるいは確定した政府出資の合意であり、したがって本日は資金調達の列全体で土台を前進させる一方、提出そのものは今後に残る。
