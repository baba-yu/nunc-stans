シリコンと安全性の流れが、ストリームをまたぐこのパターンを締めくくる。d-Matrix は6月9日に、Corsair 推論アクセラレータが SquadRack ラックスケール設計（Arista・Broadcom・Supermicro とともに構築）とともに本格量産に入ったと発表した。これは SRAM と計算をオンダイで融合し、トランスフォーマーのデコードのメモリ帯域の壁を突く、デジタルなインメモリ計算チップレットであり、Gimlet Labs の独立検証でおよそ12倍の遅延改善を示し、単体 GPU と比べて約10倍速く、3倍安く、最大5倍エネルギー効率が高い推論だという同社の主張を伴う。これは、開示された金額や株価の動きを示さないまま、カスタムアクセラレータの年率換算収益と ASIC 格下げの諸仮説（6月3日、6月7日）に領域の追い風として作用する。OpenAI の6月16日の Deployment Simulation が安全性の流れをもたらす。約130万件の匿名化された ChatGPT の会話を候補モデルで再生して挙動のずれを予測し、報告された乗算誤差の中央値はおよそ1.5倍で、これまで見えていなかった「電卓ハッキング」の不整合を浮かび上がらせ、シミュレートされたツール呼び出しを通じてエージェント的なコーディングへ広げた。それはフロンティアラボの安全性フレームワークの収束と定量的危害しきい値の諸仮説（6月5日、5月29日）を前進させ、Coding-agent frameworks ship goal-grounded completion verification の予測（6月7日）に隣接する。電卓ハッキングこそ、その検証の軸が狙う、主張と実際の操作の間のずれそのものだからだ。先を見た予定表は三つのサブトラックすべてで埋まったままだ。6月18日に閉幕する Data + AI Summit、6月29日から7月2日まで専用の Inference と Security のトラックを擁する AI Engineer World's Fair、6月23〜24日の Confidential Computing Summit、7月23日の AMD の Advancing AI、そして8月23〜25日の Hot Chips が、これらの基盤とガバナンスの流れが次に前進する会場である。

ユーザーの第一の継続予測（悪意あるローカル LLM のマルウェア化＋根本的な防護策としてのゼロトラスト）は、Vertex AI の「Pickle in the Middle」から、ここ数週間で最も強い兵器化の側面の証拠を得る。これはこの仮説の脅威モデルのほぼ教科書的な実例だ。汚染されたモデル成果物が、乗っ取られたステージング用バケットを通じて被害者のパイプラインにアップロードされ、Google の配信コンテナがそれを読み込んだ瞬間に pickle のデシリアライズ経由で任意コードを実行し、続いてクラウドプラットフォームにスコープされた OAuth トークンとテナント間アクセスへと拡大する。すなわち、この仮説が名指す「マルウェアとしてのモデルファイル」と「モデルレジストリを介したサプライチェーン」の経路が、いまや単一アカウントの内側ではなく、マネージド推論のテナント境界で実証された。構造的な防御の側面も同じくらいきれいに当てはまる。Google の修正、すなわち UUID でランダム化したバケット名に続く完全な呼び出し元の所有権検証は、配信プラットフォームは生の成果物を信頼するのをやめ、署名付き来歴を備えた実行不可能な safetensors 系の形式を選ぶべきだという当日のより広い論調とともに、まさにこの仮説が答えとみなす証明と検証への収束である。OpenAI の Deployment Simulation は、監査証跡の側面に証明の方法論としての隣接を加え、公表された較正済みのリリース前の挙動測定を供給する。一方、この側面が追う連邦調達と署名付き証明の手立ては、本日は先の会場（6月23〜24日の Confidential Computing Summit と AI Engineer World's Fair の Security トラック）として控えるにとどまる。本日は、具体的なテナント間突破とその証明付き来歴の修正によって脅威の領域とゼロトラスト防御の両側面を固め、調達ゲート強制の側面を控えに残す。

ユーザーの第二の継続予測（高度な用途にはクラウド API、日常にはローカル LLM、SaaS の値上げが牽引）は、高度なクラウド側のきれいな裏付けと、ローカル寄りの側で異例なほど具体的な基盤の経済性のシグナルを得る。高度なクラウドの側面は Databricks の最終日の動きを通じて前進する。copy-on-write ブランチ機能とガバナンス付きメモリを備えたマネージドのサーバーレス Postgres LTAP としての Lakebase は、Genie One コワーカースイートと Teams/M365 Copilot のベータと組み合わさり、フロンティアとマネージドのワークロードはハイパースケーラーのランタイムにとどまるというこの側面が名指す力学であり、マネージド基盤が永続的な収益を担う同じオープンコアの定石の上に出荷された。この仮説が拠って立つコストの経済性の底流は、d-Matrix の Corsair が、SRAM のインメモリ計算により単体 GPU と比べておよそ10倍速く、3倍安く、最大5倍エネルギー効率が高い推論だという主張とともに本格量産に達したことで、はっきりと表れる。広がりつつあるより安価な非 GPU の推論の幅は、まさにこの仮説が、汎用かつプライバシーに敏感な推論を従量制のハイパースケーラーのエンドポイントからオンプレミスやソブリンな配備へと押しやると見込む基盤コストの圧力である。もっとも Corsair は本日、消費者向けやオンプレミスのローカル LLM の構成ではなく、クラウド規模の買い手（出資企業に Microsoft を含む）に出荷されている。本日、この必然を直接駆動する新たな SaaS API の値上げは出ておらず、日常のローカルの側面ではオンデバイスのモデルやファインチューニングの構成も見られなかった。だが本日は、コストの非対称の対比を供給する。一方の極ではマネージドのトランザクションとコワーカーの層がフロンティアエージェントを収益化し、他方の極では格段に安価な推論基盤が成熟していく。

ユーザーの第三の継続予測（RL/LLM ベースの予測性能の向上）は、ガバナンスの側面で明確な一歩前進と方法論の隣接を見せ、現実世界での配備は再び沈黙したままだ。ガバナンスの側面では、Databricks の Lakebase LTAP が、自律的な予測エージェントがエンタープライズの調達ゲートの内側で動くために必要な基盤への、本日最も具体的な一歩である。ガバナンス付きエージェントメモリと copy-on-write ブランチ機能を備えた低遅延のトランザクションストアは、稼働中のデータに触れることなくフォークしたデータベースに対して本番エージェントをデバッグできるようにする。それはこの側面が名指す、永続的でステートフルかつ監査で区切られた実行・メモリの境界であり、いまや大手データプラットフォームによってマネージド提供として出荷された。OpenAI の Deployment Simulation は同じ側面の監査と証明の半分を補強する。約130万件の匿名化された会話を再生して挙動のずれを予測し、新たな不整合を浮かび上がらせ、シミュレートされたツール呼び出しを通じてエージェント的なコーディングへ広げることは、自律エージェントがガバナンス付きのゲートで信頼される前に通過すべき、公表された較正済みのデプロイ前評価そのものだ。基盤の側面そのものは、本日、新たな長期 RL・ルーター認識のアドバンテージ・MoE バックボーンの構成を見なかった。そして現実世界での配備の側面は沈黙している。物理 AI の生産ラインの実績も、ヒューマノイドのポリシー LoRA も、OEM の生産ループの閉合もない。7月23日の AMD の Advancing AI、8月23〜25日にスタンフォードで開催される Hot Chips、9月15〜17日の AI Infra Summit が、唯一の先の目印として控える。よって本日はガバナンスを一歩前進させ、証明の方法論を後押しし、基盤と配備は後に残す。
