## Summary of Findings

Ngayon, tumawid ng isang hangganan ang agentic-AI attack surface: lumipat ito mula sa teorya at mga isahang advisory papunta sa buhay at naobserbahang pagsasamantala. Ang pangunahin ay ang CVE-2026-55255 ng Langflow, isang cross-tenant na insecure-direct-object-reference na depekto (CWE-639) sa sikat na open-source na visual builder para sa mga LLM agent at pipeline, na binigyan ng CVSS 9.9 at inayos sa 1.9.1. Ang mekanismo ay isang authorization gap sa get_flow_by_id_or_endpoint_name helper: ang isang flow na nireresolba sa UUID ay walang owner check, kaya maaaring patakbuhin ng sinumang authenticated na user ang flow ng ibang tenant sa pamamagitan ng /api/v1/responses endpoint. Iniulat ng Threat Research Team ng Sysdig ang unang kilalang pagsasamantala sa totoong mundo noong June 25, at ang telemetry ang siyang kuwento -- isang operator ang unang tumawag sa GET /api/v1/flows/ para anihin ang mga flow ID na inilalabas ng endpoint na iyon, pagkatapos ay mga dalawampung segundo mamaya ay inulit ang eksaktong mga ID na iyon bilang model parameter sa POST /api/v1/responses na may input na 'leak api keys,' laban sa isang instance na nagpapatakbo rin ng mas lumang at dating CISA-KEV-listed na unauthenticated RCE na CVE-2026-33017 (CVSS 9.3). Ang istruktural na pagbasa ay ang mahinang bahagi ng mga multi-tenant agent platform ay ang orchestration at authorization plane: ang mga malabo at madaling anihing flow/run ID kasama ang isang ibinabahaging execution endpoint na ang mga owner check ay ipinapaubaya sa UI ay ginagawang isang cross-customer data-exfiltration na primitive ang isang multi-tenant agent builder.

Ang pangalawang aytem, ang CVE-2026-56663 ng AutoGPT (CVSS 8.5, inayos sa 0.6.52, inilathala June 26), ay ang katapat sa execution plane sa parehong tema. Binabaypas nito ang mga proteksyong server-side-request-forgery ng AutoGPT: mali ang paghawak ng SendWebRequestBlock na ginagamit ng mga agent para sa papalabas na HTTP call sa mga IPv4-mapped IPv6 address at hindi nito napapatunayan ang ilang IP range, kaya kayang talunin ng isang authenticated na user ang internal-IP filter at akayin ang agent ng isang tenant papunta sa mga cloud metadata service, internal admin panel, o database na hindi dapat maabot. Ang dalawang advisory ang istruktural na pinagmulan ng pinakamalalakas na bridge ngayon. Magkasama nilang pinagbatayan ang isang bagong magkasamang pares ng thesis sa iisang araw -- ang thesis na multi-tenant agent builders draw a 9.0+ cross-tenant authz CVE by Q1 2027 (Jun 27), na binhi ng Langflow IDOR bilang unang pagkakataon ng klase at paulit-ulit na pattern sa buong n8n / Flowise / Dify / LangGraph Platform / CrewAI na klase ng kapantay, at ang thesis na major AI-agent platform ships zero-trust controls as default-on by Q2 2027 (Jun 27), na ang hindi maiiwasang puwersa ay siya mismong pares ng iisang linggo ng isang pinagsamantalahang cross-tenant IDOR at isang SSRF bypass. Parehong nakakuha ng maximum 5/5 na kaugnayan sa coherence 4; pareho ang puwang na nagbibigay ang araw na ito ng mga nag-uudyok na CVE, hindi ng pangalawang platform na magpapatunay sa klase o ng pinangalanang default-posture na release.

Ang parehong dalawang CVE ay umuugma nang magkakaayon sa buong dinalang depensibong kumpol. Ang thesis na coding-agent harnesses adopt default-deny toolset gating (Jun 20) at ang thesis na OpenClaw default-deny tool and network gating (Jun 23) ay parehong tumatanggap ng direktang suporta mula sa panig ng banta -- ang remedyo ng AutoGPT (mag-upgrade, hadlangan ang papalabas na egress) ay ang manual na bersyon ng default na inaasahan ng mga prediksyong ito na magiging pamantayan. Dalawang dormant row ang muling nabuhay laban sa ulat ngayon: ang thesis na AI inference proxies gain named CISA KEV-timeline governance (Jun 10) ay muling nabuhay sa isang Layer-1 keyword match dahil ang AutoGPT SSRF ay siya mismong SSRF-on-an-agent-gateway na primitive na sinusubaybayan nito at ang Langflow IDOR ay ikinabit sa instance kasama ang isang KEV-listed na RCE, at ang thesis na agent-framework SQL tools ship read-only-by-default execution guards (Jun 5) ay muling nabuhay sa isang Layer-2 semantic match sa ibinabahaging argumento ng default-deny-execution. Ang ikatlong aytem ng araw ay isang forward-looking at tatlong-track na kalendaryo ng mga kaganapan ng AI sa halip na isang balitang pangyayari: magbubukas ngayong katapusan ng linggo ang AI Engineer World's Fair (hackathon June 27-28, pangunahing programa June 29 hanggang July 2 sa Moscone West), darating ang Advancing AI 2026 ng AMD noong July 22-23 na may Instinct MI400-series keynote sa July 23, at ang mga yugto ng AI-security -- ang AI Summit ng Black Hat USA sa simula ng August, ang AI Village ng DEF CON 34 sa parehong linggo, ang AI Risk Summit ng SecurityWeek noong August 11-12, ang Hot Chips noong August 23-25, ang AI Infra Summit noong September 15-17, at ang OWASP Global AppSec USA noong November 5-6 -- ang siyang mapa ng mga lugar. Ang may-petsang lugar ng AMD ay ang katalista para sa thesis ng paglulunsad ng AMD Instinct MI400 (Jun 27) sa coherence 4, nagbibigay lamang ng ritmo ng mga lugar sa mga thesis ng confidential-inference-tier (Jun 26) at procurement-prompt-injection-bar (Jun 23), at iniiwang malinaw ang krus-na-krus na pattern: isang naobserbahang pagsasamantala at isang bagong SSRF ang nagtulak nang malakas sa buong zero-trust agent-platform na kumpol habang ang mga sinulid ng hardware at procurement ay naghintay sa orasan ng paparating na mga lugar.
