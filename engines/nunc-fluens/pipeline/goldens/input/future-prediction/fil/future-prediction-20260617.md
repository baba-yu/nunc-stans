## Summary of Findings

Malinis na nahahati ang cycle ngayon sa apat na agos - isang AI-security break, isang non-GPU silicon milestone, isang pre-release safety method, at ang closing day ng isang malaking data-platform summit - at ang nag-uugnay na linya ay ang bawat isa ay nagpapatibay sa imprastraktura nang isang layer sa ilalim ng modelo sa halip na ang modelo mismo. Ang pinakamataas-na-coherence na suporta ay ang security thread. Ginagawa ng 'Pickle in the Middle' disclosure ng Palo Alto Unit 42 noong Hunyo 16 ang isang nahuhulaang default staging-bucket name sa Vertex AI SDK ng Google tungong isang cross-tenant remote-code-execution chain: ang isang umaatake na nakakaalam ng project ID ng biktima ay paunang gumagawa ng bucket, hinuhuli ang model upload, at nagpapalit ng isang lasong pickle na ang __reduce__ method nito ay nagpapatakbo ng arbitrary code sa mismong sandaling i-deserialize ito ng serving container ng Google, tapos kumukuha ng isang cloud-platform-scoped OAuth token. Ito ang pinakamalakas na single-incident na suporta na natanggap ng signed-checkpoint-loader na mga thesis: ang Agent-framework loaders ship signed-checkpoint and manifest mode na prediksiyon (Mayo 11) at ang Open-source serving stacks ship signed-checkpoint loading as default na prediksiyon (Mayo 12) ay parehong tumatarget nang eksakto sa load-time-arbitrary-code na pagkabigong ito, at ang remediation path ng Google - random UUID bucket names, tapos buong caller-ownership verification - ang attested-provenance na postura na parehong hinuhulaan na magiging default. Ang isang nailathalang cross-tenant break ay nagbibigay sa mas malawak na framework cohort ng masisipi na dahilan para ilipat ang artifact trust mula opt-in tungong default, bagaman wala pang agent framework o open serving stack na naglipat ng default na iyon bilang tugon.

Nangingibabaw ang data-platform thread sa lawak. Sa closing day ng Data + AI Summit, muling iniposisyon ng Databricks ang Lakebase bilang unang tunay na LTAP - isang managed serverless-Postgres database na may instant copy-on-write branching at governed agent memory - at pinalawak ang Genie tungong Genie One, isang paid-shaped na coworker suite (Genie Agents, App Builder, Lakeflow Designer, ZeroOps) na may Teams at M365 Copilot beta. Ang iisang hakbang na iyon ay malapit sa tuwirang tama sa Durable agent-execution substrate hardens into a standard primitive na prediksiyon (Hunyo 12), dahil ang pitch ay tahasang sinasabi na kailangan ng production agents ng low-latency transactional store na may ligtas na branching sa halip na isang model endpoint lamang, at pinalalago nito ang Omnigent ships as a paid Databricks-managed agent-orchestration tier na prediksiyon (Hunyo 15) sa open-core monetization na pagbabasa.
