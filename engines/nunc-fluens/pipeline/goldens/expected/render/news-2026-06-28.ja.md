3. コーディングエージェント基盤、2027年第1四半期までに三要素の権限ゲートを既定で搭載

   少なくとも1つの主要なコーディングエージェント基盤（OWASPがプロンプトインジェクションの震源地として挙げる分野で、Claude Code、AutoGPT、Dify、Roo-Codeが最も多く勧告を受けたリポジトリに含まれる）が、「ルール・オブ・トゥー」型の制約を強制する既定オンの権限ゲートを搭載する。これは、エージェントの実行が、プライベートデータへのアクセス・信頼できないコンテンツへの露出・外部通信のうち最大2つまでしか組み合わせられず、3つ目を加える前には明示的な人間の承認を求めて一時停止しなければならない、というものだ。この動きは、OWASPがプロンプトインジェクションをパッチ可能なCVEではなくエージェント型システムの構造的で修正不能な性質として捉え直したことを受けたものだ。その結果、ベンダーはトークン列をフィルタリングするのではなく、オーケストレーション層でこの致命的な三要素の組み合わせに上限を設けて緩和するしかなくなる。命令トークンとデータトークンを確実に分離する手段がないという構造的な議論ゆえに、唯一の持続的な防御は危険な組み合わせを既定で拒否することであり、競争圧力と勧告の多さが最大手の基盤をまずそこへ向かわせる。


   In plain language: AIのコーディング補助は隠された指示にだまされうるため、大手ツールは人間がOKと言わない限り危険な組み合わせを止めるようになる。

### OWASP、プロンプトインジェクションをエージェント型AIの構造的で修正不能な性質として捉え直し、コーディングエージェントを震源地と名指しする

- OWASP GenAI Security Projectは今月、State of Agentic AI Security and Governanceのバージョン2.01を公開した。その中心的な主張は、セキュリティの語りを「また一つのCVE」から設計上の制約へと鋭くする。プロンプトインジェクションは大半のエージェント型AIの事案をつなぐ「自在継手」であり、今やOWASPのエージェント型アプリケーション向けTop 10の10分類のうち6つに対応する。アーキテクチャ上の論点は、モデルがシステムプロンプト・ユーザーの要求・外部から取得したテキストを区別のない一つのトークン列として扱うため、あるトークンを命令、別のトークンをデータと確実に印付ける手段がない、という点だ。つまりこの欠陥はパッチで直すのではなく設計予算で緩和される。報告書はそうした2つの予算に依拠する。Simon Willisonの「致命的な三要素」（プライベートデータへのアクセス＋信頼できないコンテンツへの露出＋外部通信が揃うと情報持ち出しが可能になる）と、Metaの「エージェント・ルール・オブ・トゥー」（エージェントはこれら3つの性質のうち最大2つまでを満たすにとどめるか、人間の承認のもとでのみ動くべき）だ。具体的に、OWASPはコーディングエージェントが震源地だとする。追跡対象の53のエージェント型プロジェクトのうち28がコーディングエージェントで、最も多くのセキュリティ勧告を受けたリポジトリはn8n（57）、Claude Code（22）、AutoGPT（15）、Dify（13）、Roo-Code（11）であり、エージェント実行とオーケストレーションの層が最も激しい攻撃を引き寄せ続ける理由を具体的な数字で裏づける。 <a href="https://genai.owasp.org/resource/state-of-agentic-ai-security-and-governance/">OWASP GenAI Security Project - State of Agentic AI Security and Governance 2.01</a> <a href="https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/">Simon Willison - The lethal trifecta for AI agents: private data, untrusted content, and external communication</a> [OWASP GenAI Security Project - State of Agentic AI Security and Governance 2.01](https://genai.owasp.org/resource/state-of-agentic-ai-security-and-governance/), [Simon Willison - The lethal trifecta for AI agents: private data, untrusted content, and external communication](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/)
