# nuncstans — Project Instructions

## Language

- All commit messages MUST be written in English.
- All documentation and files created in this repository MUST be written in
  English.

## Commit messages

Use Conventional Commits: a type prefix, a colon, then a single sentence that
ends with a period.

    <type>: <one sentence.>

`<type>` is one of: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`,
`style`, `perf`, `build`, `ci`.

Examples:

- `chore: add Apache-2.0 license and NOTICE.`
- `docs: document the federation memory contract.`

Keep the subject to one sentence. Do not add AI-tool attribution or
co-author trailers; commit messages describe the change only.
